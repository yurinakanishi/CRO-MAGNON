# CRO-MAGNON ローカル版

ZIPをすべて展開し、`start-local.cmd` をダブルクリックすると、このPCでゲームが起動してブラウザーが開きます。Node.jsのインストールやインターネット接続は不要です。

ゲーム画面は `http://localhost:3000/` です。起動用の黒いウィンドウを開いたまま遊び、終了するときはそのウィンドウで Ctrl+C を押してください。最後の状態を保存して終了します。

`local-visibility.json` の `mae` / `maruimo` / `howkey` は、`false` で非表示、`true` で表示です。この持ち運び版では、変更して保存した後にゲームを終了・再起動し、ブラウザーを再読み込みしてください。元のモデル・画像は同梱しているので、再表示できます。

このフォルダーの `.cro-magnon-save` に10秒ごとに自動保存します。以前の版のフォルダーや保存データは書き換えません。フォルダーごと保管してください。この配布ZIPに制作PCのプレイヤー情報や保存データは含めていません。

既に同じ版が起動している場合は、そのゲーム画面を開きます。別のゲームが3000番を使っている場合は停止せず、エラーを表示します。

これは通常のローカル版です。展示用の別サーバーやPC1を起動する必要はありません。
