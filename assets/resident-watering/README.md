# 住人へ畑の水やりを頼む

既存の三作物・48区画と、住人の採集・夕食・世帯の旅をつなぐ任意の手伝いです。実装計画は [RESIDENT_WATERING_PLAN.md](../../RESIDENT_WATERING_PLAN.md)。手動移動・ジャンプ・現在のタイトルと動作を継続します。

## 遊び方

1. 畑のそばで湾の案内を開き、作物を植えます。
2. その区画を選んで「住人に水やりを頼む」を押します。担当する住人と現在の行動を確認できます。小さい画面ではポーズメニューから湾の案内を開けます。
3. 住人は朝と昼、夕食の実を採った後に泉へ歩き、3秒汲んで水を2まで持ちます。畑へ歩いて戻り、3秒の水やりで成長を始めます。ベリーと香り草は水1、火根草は水2です。
4. 実った作物はプレイヤーが収穫します。植え直した畑は未依頼に戻るので、必要なら改めて頼みます。

取消は畑のそばから行います。頼んだ後でも自分で水をやれます。住人の持ち水は失われず、次の依頼へ使います。手伝いは一人一日一つまで。訪問中の住人も手伝いますが、会話・世帯の出発・夕食と休息を優先します。当日中に運びきれない担当は翌朝に続け、出発すると別の住人へ引き継ぎます。

## 保存・同時操作

作物の依頼時刻と、住人の持ち水・最後に水をやった日と区画と作物を保存します。旧保存は未依頼・水0・未記録です。途中の作業時間は保存せず、担当は復帰時に選び直します。部屋が無人になったら途中の作業を捨て、過去の日数分をまとめて処理しません。

距離・遮蔽・水の必要な作物・依頼の一致・担当・日別回数・停止・作業時間はサーバーが検査します。取消と再依頼が同じ時刻でも古い作業時間を引き継ぎません。手動水やりとの競合では一度だけ成長を始めます。プレイヤーの種・水・食料・実績、共同食料、頼まれていない畑は自動で変えません。

## 検証と範囲

12個の追加テストで三作物×四季、全四集落の8人と集い場に訪問中の8人の経路、夕食、翌朝への継続、日別順番、取消・手動水やり・植え直し、遮蔽・会話・出発・ジャンプ・未完の作業、保存・旧保存・無人を検査します。8プレイヤーによる依頼と水やりの競合と、作物が完成した時の即時配信も確認します。5人は接続の初期設定で、住人数・区画数・世界の規模の上限ではありません。

全378テスト、strictを含む分離ビルドと作業ツリー型検査、依存境界を確認。初回の全体並列実行では既存の切断検査の固定40ms待機が不足したため、実際の部屋の解放を最大3秒待つ検査に変更しました。完了条件を保持したまま全件を再確認しています。

ブラウザーの再現は [qa-resident-watering.mjs](../../scripts/qa-resident-watering.mjs)。専用サーバー・QA部屋のChrome2画面と通信3人で882観測、衝突違反・ブラウザーエラー0。開始位置・材料・訪問状態・日別記録と初期資源在庫・共同食料の焼き根1個・3回の時計変更は準備値です。歩行と採集・汲み・水やり・夕食は実時間。時計の変更は休息中の作物の成長も進めます。作物の完了時刻を直接変更していません。Gamepad入力はAPIの模擬で、物理機器の検証ではありません。詳細は `qa-summary.json` と `movement.json`。初回QAの横長画面で非表示のHUDを押そうとした手順を、通常のポーズメニュー経由に直して全行程を再確認しました。
