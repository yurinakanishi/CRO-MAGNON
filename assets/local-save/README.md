# 通常Nodeサーバーの自動保存

2026-09-09。既存ゲームの続き。仕様は [LOCAL_SAVE_PLAN.md](../../LOCAL_SAVE_PLAN.md)。通常 `node server.mjs` と `npm start`、開発用 `npm run dev` に適用する。展示パッケージ・Cloudflare側の保存方式は変更しない。

## 遊ぶ人へ

- 3000番をこのPCの `localhost`／`127.0.0.1` で遊ぶときは、メニューの「設定」→「部屋の進行をリセット」から最初に戻せる。確認画面の「やめる」は進行を変えない。「リセットする」で同じ部屋の世界と全員の持ち物・個人の進行（オフラインの再開情報も含む）を初期化し、接続中の画面は名前・キャラクターを保って自動で再参加する。他の部屋は残る。
- 共有世界と個人の進行を10秒ごと、参加／離脱後、正常終了時に保存する。メニュー下部に最後の保存時刻を表示する。
- 「タイトルへ戻る」→「はじめる」、同じブラウザーを閉じて開き直す操作、サーバーの再起動後も再開できる。空室と個人の再開情報に2分の期限を設けず、保存人数を100人で切り捨てない。同時接続上限5人とは別の制限である。
- 個人の再開には同じブラウザープロフィール、サイトのアドレス、接続先と部屋を使う。別の端末／ブラウザーへのアカウント移行は未実装。ブラウザーのサイトデータを消すと再開情報も消える。保存を拒否された時は画面へ表示する。
- キャラクター／部屋の変更画面で明示して参加し直す操作は、従来どおり個人の進行をリセットする。タイトルのメニューは「はじめる」「あそびかた」の2項目のまま。
- 書込が失敗した場合はメニューと通知へ表示し、次の保存で再試行する。強制終了・停電では最後に成功した保存まで戻る場合がある。10秒は保存の試行間隔であり、失敗中まで含めた損失の上限ではない。
- 暦・作物の成長期限・世帯の滞在期限は既存の時計に従う。停止中の日数分の住人の採集・水やり・夕食をまとめて生産／消費しない。途中の作業・交換・跳躍・移動入力は復帰へ持ち越さず、船と騎乗は既存の安全な復帰処理を使う。

## 運用と復元

既定の保存先はプロジェクト直下の `.cro-magnon-save/`。`CRO_SAVE_DIR` で別の専用ディレクトリを指定できる。公開素材 `public` と配信コード `dist` 内は拒否する。既定の保存先はGit対象外で、通常のビルドは触らない。

`world.json` が現在、`world.backup.json` が前回の有効な保存。SHA-256、形式の版、世界の版、必須データと既存の復元処理で検証する。一時ファイルを書き切ってファイルをflushした後、同じディレクトリで置き換える。両方を同時に削除する処理はない。最大64MiBを超えた場合は失敗を表示し、前回の保存を残す。大人数・多数の部屋では今後分割保存を検討する。

現在のファイルが破損して予備が使える場合は、破損した原本を `world.corrupt-日時-識別子.json` に残して予備を読み、ログと画面で知らせる。両方が壊れている場合と未対応の将来版では起動を止め、空の世界で上書きしない。古いexportStateの生JSONも検証して読み込めるが、古いチェックポイントを自動探索・再適用しない。

手動の保管・復旧はサーバー停止中に専用ディレクトリ全体をコピーし、別の保管場所へ残してから行う。保存ファイルには私的な再開トークンを含むため、公開素材・Git・公開QAへコピーしない。QAの要約にはトークンを含めない。強制停止で残った `.tmp` ファイルは復元対象にしない。

同じ実ディレクトリの同時書込は、正規化したパスから決めるローカルTCPポートの占有で防ぐ。Windowsの強制停止後もOSが解放する。ポートの偶発的な競合では安全側に起動を止める。ロックは同一PC内の仕組みで、複数PCから同じネットワーク保存先へ書く運用は対象外。共有ドライブ・クラウド同期フォルダーの原子性や停電耐性は未検証。

開発用の監視処理は親プロセスのIPCで終了を頼み、最終保存が成功してから再起動する。10秒で終了しない場合は強制停止して再起動を中止する。通常のCtrl+C／SIGTERMも最終保存を試みるが、Windowsのタスク終了や `Stop-Process` は正常終了を保証しない。Web経由の停止・読み込み・書き換えAPIは追加しない。

`createGameServer` を直接使うテストや展示側は従来のメモリ内動作を維持する。ディスク保存を明示して使う別のNodeホストは `createPersistentGameServer` を使う。Cloudflareの既存保存方式と制約を混同しない。

## 検証

`tests/local-save.test.mjs` は実ファイル・直列書込・予備・破損原本の保持・未対応版・失敗後の再試行・二重起動・111人の再開情報・一年の無人経過・正常／強制プロセス終了・タイトルと明示変更・静的配信の非公開・起動失敗後の保持を検査する。保存人数の検査は同時111人の負荷試験ではない。

`scripts/qa-local-save.mjs` と親IPC限定の `qa-local-save-host.mjs` で、実Chrome2プロフィールの手動移動→タイトル再開→Chrome終了→別プロセスのサーバー終了／起動→同じChromeプロフィールからの再開を確認する。持ち物・装備・畑・共同食料・貝塚・住人の持ち水は明記した準備値。移動と再開は実操作で、時計変更はない。実ファイルの書込失敗と予備復元を画面で確認する。1440×900、390×844、844×390と模擬Gamepadを使う。物理コントローラー・物理タッチ端末・長時間負荷は今回未検証。

通常3000番への反映と準備値のない確認は `rollout.json`、検査結果は `qa-summary.json`、素材の保持は `assets-qa.json`。画像はGit外の `output/playwright/local-save-20260909/` に記録する。既存68GLB・9タイトルPNGを保持し、新規モデル・依存・公開デプロイ・展示更新はない。
