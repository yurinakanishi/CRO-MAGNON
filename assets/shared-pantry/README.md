# 共同の食料置き場

2026-09-08。[計画](../../SHARED_PANTRY_PLAN.md)を先に作成し、既存の四集落の炉へ食料の分け合いを追加した。

## 遊び方

「三つの岸の湾」→「共同の食料置き場」で、集落と食べ物を選ぶ。選んだ炉の9m以内で1つずつ預け、受け取れる。「この炉へ歩く」で既存の徒歩経路を使う。

| 食料 | 食べた時の元気 | 既存の用途 |
| --- | --- | --- |
| ベリー | +25 | 種との交換、世帯の旅支度、宴 |
| 焼き肉 | +45 | 旅先の食事 |
| 焼き魚 | +30 | 食事、宴の食料3個分 |
| 焼いた貝 | +20 | 食後の殻を貝塚へ、ネリの手伝い |
| 焼き根 | +35 | 食事、宴の食料3個分 |
| 香草焼き根 | +50 | 食事、宴の食料3個分 |

食料置き場はそれぞれ合計48個、初めは空。プレイヤーが持ち込んだ分だけを共有し、取り出した食べ物は通常のもちものになる。預けた分は他の旅人も受け取れる。一人一日3個までという受取回数は四集落で共通。国・種族・以前の寄付経験を問わず利用できる。預け入れは回数を消費せず、受取回数も戻さない。日付は既存の4分のサーバー暦。

容量と上限は五人の人口を想定したものではない。現在の接続設定を変えず、8人の同時受け渡しでも同じ処理を検証した。食料の量と回数はゲーム内の配分の調整値として独立している。

## 安全な受け渡しと保存

品目・場所・距離・遮蔽・作業中・在庫・所持上限99・全食品の容量48・日付・回数をサーバーが検査する。複数人が最後の一個を同時に要求しても一人だけが受け取る。失敗時に食べ物や受取回数を片側だけ消費しない。共有在庫と個人の一日の回数は既存のexport/importと同じタブの再接続へ含める。古い保存には空の置き場と未受け取りを追加する。

選択・数量・受取残数を専用画面へ表示し、スナップショット更新でボタンや選択のDOMを作り直さない。遠隔、満杯、空、回数済み、作業中などの理由を表示する。食事は従来の操作を使い、元気満杯や貝殻満杯も案内する。成功時の通知は既存の通知方針を引き継ぎ、追加のポップアップは作らない。

住人の自動消費、腐敗、ログアウト中の減少、空腹死、通常のNodeディスク永続化は追加していない。宴の持ち寄り箱とは別の在庫で、宴が成立しても置き場の食料は減らない。

## 歴史と創作

食べ物を分け、炉に集まり、場所を繰り返し使うという世界観は [考古学の調査](../../WORLD_SETTING_PLAN.md)を土台とする。四か所の仕組み、容量、一日の配分、六食品と保存期限を設けないことは創作。古代の倉庫建築や実証された配給制度、調理済み食品の現実の保存性とは説明しない。既存の炉・天幕を利用し、物理的な倉庫、追加のメッシュ・テクスチャ、新規GLB・依存パッケージは0。
