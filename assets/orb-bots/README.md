# 5色のbotたち

添付画像の白「＾＾」、青「＞＜」、緑「＋＋」、紫「○○」、オレンジ「－－」を、それぞれ独立した3Dキャラクターとして制作。操作人物に各色1匹ずつ付き添う。

- **C**：押すたびに次の1匹を投げる。現在は追加4種類を含む全9種類。
- **Z** またはメニュー内の色ボタン：投げ始める種類を選ぶ。
- **Q**：仲間を呼ぶ。投げたbotは呼ぶまで着地した場所で待つ。
- コントローラー：**左スティック押し込み**で1匹ずつ投げる、**十字キー↑**で呼ぶ。メニュー「botたちを選ぶ・呼ぶ」から全種類を選べる。
