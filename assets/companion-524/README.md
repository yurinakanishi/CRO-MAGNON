| 操作 | コントローラー | キーボード／画面 |
| --- | --- | --- |
| 近づいて撫でる | 下側の **×** | **V**／「524を撫でる」 |

2.6m以内で、壁越しではなく、攻撃・ジャンプ・乗り物・調理などの最中でなければ撫でられる。×はこの条件で撫でる操作になり、それ以外の乗降・メニューの既存動作を維持。撫でると1.8秒の軽い弾みと左右の傾き、消えていく5つのハートが出る。1.2秒の連打制限があり、最後に有効に撫でた1人を追う。

追従ではプレイヤーの後ろ約2.1mを目指し、静的障害物・地形の通行判定に従う。歩行クリップは使わず、床の高さに合わせて浮く。帰還は通った経路を記録して逆にたどり、途中で薪などが再出現して塞がれた点は避ける。接続終了・行動不能・乗船・遠距離ワープでも帰還する。保存時の位置と帰路を保持し、再起動時の追従者は古いプレイヤーIDを追い続けず帰還する。旧保存にはキャンプの524を追加する。
