# ゲーム全体の不具合調査・修正 — 2026-09-07

入力、画面表示、採集・交易、戦闘・狩猟、調理、騎乗、地域移動、素材読込、通信と再接続を調査した。再現できた不具合を修正し、通常の3000番サーバーで反映を確認した。既存の作業内容と全31モデルを保持し、GLBの新規制作・交換は行っていない。

機械可読の実測値と配信ファイルの照合は [bug-audit-qa.json](bug-audit-qa.json) に記録している。

## 修正内容

| 症状・再現条件 | 修正と確認 |
|---|---|
| クリック移動中にチャットへ入力すると、裏で歩き続ける | チャット・ダイアログ・画面離脱で移動と騎乗への接近を停止。実画面でチャット入力中の移動量が約1.785 mから0 mになった。押しっぱなしのキーは離すまで無効にする。 |
| Ctrl+HやCtrl+Eなどのブラウザ操作が、ゲームのヘルプ・採集を発動する | Ctrl・Alt・Meta・IME変換中を除外。WASDは物理キーに対応し、配列の変更でも押下と解放が一致する。実画面と回帰テストで確認。 |
| フォーカスしたボタンでEnterを押すと、ボタン操作よりチャットが優先される | 標準のボタン・リンクのキーボード操作を保持。ヘルプの「探索をはじめる」をEnterで押して閉じることを確認。 |
| 小型・横長画面で下の操作が画面外へ出る／重なる | 実際の表示領域と操作欄の高さに追従させる。390×844、844×390、360×640でスクロールのはみ出しと操作ボタンの画面外配置が0。短い縦画面ではチャット表示中の操作欄を隠す。 |
| クノイチが自動接近後に止まる距離では刀が届かない | 刀の射程内で、マンモスの体に重ならない位置まで接近。全種族の射程テストと、スマートフォン表示で刀4発→討伐→生肉採取を確認。 |
| 対象未選択のまま討伐すると、遠くの生きたマンモスへ表示が移る | 近くの死体・生肉を対象に保つ。騎乗中のマンモスは狩猟対象から除き、乗り手には採集の案内を出さない。 |
| 木・壁・橋の欄干越しに採集・交易・拠点への貢献・調理ができる | 対象自身の形だけを除外した見通し判定をサーバーと操作案内で共有。オルへの地図の到着位置も欄干の手前から、交易できる側の座標(70,39)へ修正。通常の地図移動後に交易を確認。 |
| 最も近い資源の持ち物が99個だと、近くの別の資源も採れない | 見通しと所持数を満たす資源から選ぶ。遮蔽物・満杯・別資源の組み合わせをサーバーの回帰テストで確認。 |
| 攻撃動作中・調理中に別の持ち物操作が重なる | サーバーで動作の競合を止める。攻撃による調理中止と明示的な調理中止は保持し、中止で生肉が減らないことを確認。 |
| 交易で増えたベリーなどが「採集」の目標達成に数えられる | 実際に採った資源の個数をサーバーで記録。交易で値が増えず、短時間の再接続でも維持される。 |
| 地形をクリックした後、遠い地域へ移ると新しい地面がクリックできなくなる | 地形のインスタンス配置変更時に古い境界球を無効化。Three.jsの実際のRaycasterで、元の場所と128 m移動後の両方に命中することを検証。 |
| 通信の詰まりで資源の更新を受け損ねると、採取済みの資源が表示に残る | 通信が戻った最初の状態配信で資源・拠点を含む全体状態を再送。サーバー送信バッファの混雑を模擬して検証。 |
| 通信切断・再読み込みで別人として参加し、持ち物と位置を失う | タブ専用の復帰情報とサーバー内の2分間の保持を追加。同じID・持ち物・位置・元気での復帰、古い接続の置換、騎乗解除、期限切れと明示的なプロフィール変更を検証。 |
| 復帰待ちの間に満員になると、持ち物を保って参加し直す操作がない | 満員時に「保存した持ち物で再接続する」を表示。実画面で満員の拒否→空席→再試行し、木8・石3・ベリー2・生肉2と同じIDを保持。5人の上限は維持する。 |
| 持ち物・仲間の画面を開いたままだと内容が古くなる | 調理終了後の持ち物、操作の有効状態、石斧、入退室後の人数・一覧を更新。調理中の持ち物画面と、5人から4人への入退室で確認。世界地図も開いている間は更新する。 |
| HTTPのLAN接続でWebCryptoがなく、検証やLODのテクスチャ共有が成立しない。モデル確認画面は読込に失敗する | 同じSHA-256結果を返す共通処理を追加。通常時はWebCrypto、使えない環境では小分けに処理して検証する。パディング境界・部分配列・大きな入力を標準実装と照合。WebCryptoを無効にしたブラウザーでゲームとモデル確認画面を確認。 |
| 素材読込失敗やWebGLの消失後も、見えない画面の裏で移動・攻撃できる | 描画失敗時に移動を止め、ゲーム操作を無効化。GLB取得の失敗を注入し、W/F操作後も位置と攻撃回数が変わらないことを確認。WebGL消失も別に検査。 |
| 外部フォントへの通信失敗が発生する／構文検査が無視された一時ファイルを参照する | 外部フォント読込を除き既存のローカル代替フォントを使用。構文検査はsrc・shared・scripts・testsの実ファイルを列挙する方式へ修正。 |

## 検証した範囲

- 開始時の既存135テストに17件の回帰テストを追加し、**152件成功・失敗0・省略0**。`npm run check` は118ファイル成功、`npm run verify:assets` は31モデル成功、`git diff --check` も成功した。
- Chromeの独立した2画面とWebSocket参加者3つで最大5人。5画面すべてを描画した試験ではない。観測した28,721通信状態で静物・動的物体への貫通0、乗り手の座標不一致0。観測には検証用に位置・持ち物を設定した状態を含む。
- 6種類すべてのキャラクター選択と攻撃、採集、石斧制作、交易、木12・石6による野営地完成、肉の採取、調理完了・中止・食事を実操作した。こぐまの騎乗・走行・降車、クノイチによる狩猟も確認した。
- 草原側で各境界の手前へ検証用配置し、雪原・氷原・火山・砂漠への4つの境界を通常の移動処理で越えた。全640 m四方を徒歩で踏査した試験ではない。
- 砂漠→火山→砂漠で、12秒の保持時間が過ぎた地域素材の解放・再読込を確認。観測時の地形区画は最大69、地域表現の元geometry・textureの追加複製は0。記録したFPSは境界・地域観測で60、通常サーバーでの最終確認で57。常時60の保証とはしない。
- カメラのドラッグ・ホイール・ズームボタン・自分の位置への復帰、ヘルプ、手帳、チャット送受信と開閉、招待のコピー、環境音の切替、全画面の切替を実操作した。招待URLに復帰用の情報は含まれない。
- 小型画面はデスクトップChromeの表示領域で検査した。実機のiOS/Android、別の物理LAN端末、長期間の連続稼働は今回の検証に含まれない。

## 通常サーバーへの反映

起動済みの3000番開発サーバーで最新コードを確認した。`BUG-AUDIT` 専用部屋で起動、再読み込み時の復帰、攻撃、仲間画面を検証し、主要6ファイルの配信バイト列を作業フォルダーと照合した。手動でサーバーを再起動したり、過去のチェックポイントを再適用したりしていない。

## 復帰の条件と残る制約

復帰は同じタブの復帰情報を用い、切断から2分間サーバーのメモリで保持する。空席が必要で、復帰時に元の位置がふさがれていれば安全な近傍へ置く。切断時は騎乗・移動・調理・未着弾の攻撃を解除し、生肉を残す。プロフィール画面で明示的に参加し直す操作は従来どおり個人の進行をリセットする。

サーバー再起動後の永続保存は追加していない。期限を超えた復帰や新しいタブからの同一人物の復帰も保証しない。既存の髪・毛皮・葉の形や服の変形、屋内に入れないこと、自由な山登り・ジャンプ・対人戦がないことは今回の動作修正の対象外である。

今回の再現ケースは修正・再検証したが、有限のテストから、あらゆる端末・操作で不具合が一切ないと断言することはできない。
