## 遊び方と挙動

- 初期焚き火そばの `(51,53)`。半径0.30m。524とは別個体。
- 2.6m以内で V／画面の「リモねこを撫でる」／PS4の×・Switch ProのB。人物は足裏を置いたまま膝と腰を曲げ、猫が手元へ来てから1.6秒で2回撫でる。
- 身長と腕長に合わせて7種類の人物を調整。手は猫のアニメーション中の `PetContact` 骨を追う。武器を隠し、歩行・攻撃・ジャンプ・人物変更などで中断できる。
- 撫で終わるとなつき、約1.65mを目安に追従する。振り向くだけで周囲を回らず、止まると減速する。T／画面ボタン／メニューからキャンプへ帰せる。切断・行動不能・乗船・遠いワープでも帰還する。
- 実際の近接攻撃・魔法が命中すると方向別にノックバックし、0.5秒後から2.1秒の威嚇。低くかがみ、耳を伏せ、口を開ける。「シャーッ！」と短い呼気音（既存の音設定がオンの場合）。威嚇中は撫でられず、なつきは解除される。体力・死亡・戦利品・反撃は持たない。
- 状態とイベント時刻をサーバーが共有する。旧保存へ追加し、新保存の位置と帰路を保持する。復元時に古い追従者IDは引き継がない。

## 残る制約

毛束はTRELLISの立体表面で、毛の物理や一本ずつの毛ではない。開いた毛束面・非多様体部分を含むため3D印刷用の閉じた立体とはしていない。全メッシュ組の自己交差を証明する検査はしていない。
威嚇音はフィルター付きノイズによる呼気音で、猫の録音ではない。実スピーカー、物理コントローラー、実展示画面、長時間連続稼働は未検証。
展示配布の状態は `docs/rimo-neko-delivery-2026-09-28.md` を参照。
