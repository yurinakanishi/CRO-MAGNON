# 木材から丸木舟を作り、海を渡る

2026-09-08。ユーザー指定「木材を使って、船を作って、海を渡れるようにしたい」をローカル版へ実装。既存の4,096 × 2,048 mの大陸・海岸線・海面を使う。公開版へのデプロイやCloudflareの契約変更は行っていない。

## 遊び方

1. 木材12個を集める。「海岸へ」で近くの造船可能な海岸まで走る。
2. 「船をつくる」で丸木舟を作る。持ち物画面にも同じ製作項目がある。
3. 岸からB／「船に乗る」で乗船。WASD・海面クリック・地図の海上目的地で操船し、Shift／走行ボタンで速く進む。
4. 岸に近づきB／「岸へ降りる」で上陸する。船はその場に残り、仲間も使える。

木材消費、海岸と障害物、乗降距離、占有、衝突はサーバーで確定。製作失敗では木材を消費しない。1隻1人、部屋で最大5隻。通常4 m/s、速い操船7 m/s。海上で降りたり陸へ船を走らせたりはできない。採集・攻撃・調理・遠征・マンモス騎乗は上陸してから。到達困難な長距離の航路検索は止め、近い海面の選択や手動操船を案内する。「海岸へ」は同じ陸塊の半径128 mで候補を探すが、世界中すべての位置から到達できる保証ではない。

切断・同じタブの再読み込みでは船と乗り手を最後に乗った安全な岸へ戻し、持ち物を保持する。船が航行している間は、この復帰用係留位置を別の船が占有できない。共有船は既存のワールド保存・復元に含める。旧セーブに船がなければ空の船一覧として復元する。Node版の通常復帰は既存の2分間メモリ保存。Cloudflare用の共有コアにも実装したが、公開動作を今回検証・更新したものではない。

## 制作

`dugout-canoe` Candidate 1 / revision 02。built-in imagegen参照画像 → ローカルTRELLIS-2（1024、seed 42）→ Blenderの均一変換・形状を保つ軽量化 → 埋込画像の圧縮 → exact GLBの7方向×材質／clay比較 → ゲーム組み込み。

全長3.8 m、幅約1.0 m、高さ約0.91 m、62,145三角形、4,732,516 bytes。SHA-256: `6e77ae6df54f19a450d460b70ee35596e9703942d5d18bcdbf6b35f066e964e4`。denseの282,486三角形と空洞・船縁・船尾の座面を比較した。revision 02はrevision 01の非画像バッファをバイト単位で保持し、画像圧縮PSNRは49.66／51.03 dB。剛体の船に骨は不要。6種類の人物は既存の骨格で着座し、降りると姿勢を戻す。5隻のgeometry・材質・textureを共有し、125 m以遠は描画を省く。既存GLBは保持し、可視プリミティブや読込失敗時の代用モデルは追加していない。

元画像、dense GLB／PLY／texture、加工スクリプト、両revisionと比較画像は `model/` に保持。canonical保存結果は `canonical-qa.json` を参照。
