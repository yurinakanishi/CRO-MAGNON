# 女性2体の顔の補修

2026-09-21。クロマニョン女性とネアンデルタール女性の目・頬・口元を作り直し、`model-face-r10.glb` を採用した。通常3000番でモデル、LOD、人物画像、マニフェストの配信SHA一致を確認済み。旧GLB・旧LOD・旧人物画像・不採用の試作は保持している。

Gitには採用済みの `public/models/` のGLB、参照画像、制作記録と代表的な検証画像を含める。約2GBの復元途中のGLB・PLY・画像は各 `work/` のローカル保管とし、SHAを記録したJSONはGitへ含める。`verify-female-faces.mjs 10 --no-write` は採用済みの配信ファイルを直接検証するため、途中のバイナリを持たない取得直後の環境でも実行できる。新しいrevisionの制作・再生成にはローカルTRELLIS-2と途中データが必要になる。

代表画像は `qa/finished-faces.png`、ゲーム検証結果は `qa/game/report.json`、全動作の比較画像は `qa/poses/` に保存した。全画面と動画は従来どおりローカルの `output/` に保持する。

## 制作と保持範囲

元の `model-human-r10.glb` を実Chromeのカラー／無彩色で確認し、目の周囲の突起、尖った面、凹凸を再現した（`output/playwright/female-faces/before/`）。形状に問題があるため、色の修正だけでは解決しなかった。

`request.json` の指示でCodex imagegenから成人女性の頭部参照を各1枚生成し、ローカルTRELLIS-2へ順番に渡した。設定は1024、seed42、PBRモデル512、atlas2048。復元はクロマニョン女性約1,226秒、ネアンデルタール女性約1,571秒。各 `work/trellis/reconstruction.json` に引数・時間・SHAがある。Claude、Tripo、プリミティブによる人物の代用は使用していない。

生成参照を顔のUVへ投影して目と肌色を調整。クロマニョン女性の額に重なった細い髪の面は、直下に復元済みの額がある部分だけを除いた。meshoptimizerの境界保持と顔の頂点固定を使い、滑らかな顔の形を保持して髪などを減らした。Blender QEMの試作と、UV境界を強く減らしたr09は、裂け目や色の乱れが出たため不採用として保持した。

元の首の断面に頭部を接続。クロマニョン女性は1.400m、ネアンデルタール女性は1.315mより下の体の三角形と頂点属性を保持した。首の色と法線を体へなじませ、クロマニョン女性の既存の三つ編みの色を追加のアトラスで合わせた。r10では新しい後ろ髪の下部へ既存の三つ編みのウェイトを移し、7cmの範囲で頭の骨から切り替える。元の22骨、逆バインド行列、全10クリップ、元バイナリの先頭は保持する。

顔は近距離でも立体として表示する。画像の板への置換や、表示だけを覆う処理は使っていない。髪は復元された塊状の形であり、髪揺れの物理、全自己交差、長時間負荷は未検証。

## 検証

- `validation-r10.json`：体の55,079 / 53,191三角形と76,432 / 62,688頂点の属性を元データと照合。全10クリップを120Hzで走査し、首の接続207,570組でずれ0m。LODの骨順・逆バインド・全頂点属性も照合。
- 実GLBの前・斜め・横・後ろ、無彩色、全10動作各3姿勢の60画面を確認。`output/playwright/female-faces/final-r08/`、`poses-r10/`、配信そのものの `adopted-r10/`。
- 関連32テスト、TypeScript、365 JS構文、依存境界、変更スクリプトの書式が通過。全8体の動作配信検証も通過（`output/female-face-final-tests.log`、`output/female-face-motion-delivery.log`）。
- 実Chromeの画面2人＋通信3人で、人物選択、歩行、走行、攻撃、ジャンプ、相手側の動作、距離LODの往復、再読込、390×844 / 844×390を検証。ブラウザーエラー0。最新の結果は `adoption.json` の `gameQA` を参照。敵の除去、初期座標、確認カメラは保存のない独立した検査世界の準備値で、移動・攻撃・ジャンプは通常のキー操作。
- `delivery.json`：通常3000番の8ファイルがローカルとSHA一致。通常サーバーの再起動、ユーザーの保存変更、展示／PC2更新、公開デプロイは行っていない。

全素材検証は、このホストで変更前から不足している別モデル `neanderthal-hunter` の元参照画像により停止する。`output/female-faces-baseline-assets.log` と `output/female-faces-final-assets.log` に同じ欠落を記録。今回の配信・動作検証の成功と、過去の制作資料を含む総合検証の未完了を区別する。

## 再現用スクリプト

完成候補は上書きしない。再実行時は未使用のrevisionを指定する。

1. `generate-female-heads.mjs`：参照からTRELLISの高精細GLBを作る。
2. `bake-female-face-colour.mjs`：採用した色はクロマニョン女性r05、ネアンデルタール女性r01。
3. `simplify-female-head.mjs <色GLB> <出力GLB> .12 .004`：顔固定・境界保持。採用入力は両方の `head-reduced-r04.glb`。近距離では `--permissive` を使用しない。
4. `build-female-faces.mjs <revision> <key> head-reduced-r04.glb`：体との接続・首の色・保持した三つ編みの色。採用の表面はr08。
5. `bind-female-hair.mjs <接続revision> <新revision>`：r08→r10で後ろ髪のウェイトを修正。
6. `build-female-face-lods.mjs <revision>`、`verify-female-faces.mjs <revision>`、`qa-female-faces.mjs` で実ファイルを確認する。
7. SHAを記録した外観レビューと検証に合格してから `adopt-female-faces.mjs <revision>`。`qa-female-faces-game.mjs` と配信照合を別に行う。

ライブラリ資料はContext7でThree.js、Blender、sharp、meshoptimizerを確認した。meshoptimizerはローカル1.1.1を使った。
