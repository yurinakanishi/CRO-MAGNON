## 動作とゲームへの接続

`Idle_Loop / Walk_Loop / Run_Loop / Attack / Gather / Craft / Give / Eat / Wave /
Jump / Ride_Loop / Boat_Loop / Downed` の13クリップ。60Hzで作画し、ゲーム側の既存Mixerで再生。
下半身の触手を順番に送り出す空想生物用の歩き方で、実在タコの歩行資料からの再現とは扱わない。
歩行0.8m/s・走行2.2m/sに接地中の後送りを合わせ、ルート移動は焼き込まない。

Fで長い右腕を前へ突き出す。判定時刻0.4秒、先端の前方距離1.6603mに対し、
サーバーの射程は身体半径込み1.65m。ダメージ22、間隔1.1秒、体力消費3。
既存の壁判定・向き・味方保護を使用し、触手の武器モデルを追加で重ねない。
石斧を制作した後も攻撃の見た目は触手を維持する。

猫と524には右触手の20節を曲げて触れる。下半身はその場に保ち、対象は胴体の外側まで近づく。
マンモスでは下側の触手を背中へ載せ、舟では専用の姿勢を使う。解除後は全骨の位置・回転・倍率を復帰。
既存人物への変更、持ち物、食事、採集、制作、ジャンプ、ダウン、通信同期に対応する。

## 制作と保持

元画像 → imagegenの立体復元用参照v2 → ローカルTRELLIS-2 v0.8.1（1024、seed42）→
形状を保つ限定平滑化とQEM → 元メッシュに合わせたリグと動作 → 配信GLBの再読込検査。
可視形状をプリミティブで置き換えていない。リグ作成中は元の面・UV・アルベドを保持した。
参照v1/v2・プロンプト・復元失敗・全リグrevision・Blender編集ファイルを保存する。
v3プロンプトは未実行の草稿。完成候補は1体で、修正版は別revisionとして残した。

制作正本: `../threed-model-creation/models/maruimo-octopus/`。
全ファイルの保存先とSHAは本フォルダーの `archive.json`、修正理由は `revision-history.json`。
正本の `qa/candidate-1/viewer.html` はGLBを内蔵し、13動作・低速・停止・時刻変更を備える。
今回のブラウザー操作ツールはfileスキームを許可しないため、独立HTMLの起動は未確認。
ゲームと既存HTTPプレビューでは配信版を確認済み。

再制作は `workflow/` を使用する。`qa-build.ps1` は静止画・動作コマ・LODを作り、
`build-lod.py` の後に `align-lod.mjs` で元のバインド姿勢を復元する。
採用r10は同じ工程の `lod-bind-r03.glb`。初回stagingスクリプトは既存採用の上書きを拒否する。
