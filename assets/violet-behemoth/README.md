**2026-09-12 旧版の最終：rig revision 10。** 接地した突進・回転の別々の予備動作、専用動作付きの毒液、突進の波打つ尾と回転の遅れてしなる尾を採用した。位置は `(−25, 70)`、表示倍率2.5、縄張り30m。詳細・動画・検証は [旧版の修正記録](RIG_UPDATE_2026-09-12.md)。

**同日追補：敵として強化・帰還後の索敵を修正。** 突進22.5m/s（7.5→11.25m/sの後、さらに2倍）、回転の溜め0.6秒、毒液18m/s・射程30m・着弾半径2.4m。帰還中も帰還直後も足音と被弾に反応する。r10モデルを保持し、攻撃時間に合わせて全ポーズを再生する。[強化の設定と検証](STRENGTH_UPDATE_2026-09-12.md)が現在のゲーム仕様。以下の初期仕様は履歴。

ユーザー支給画像を基に、全長6mの敵をヨーロッパの草原の集落近くへ追加。最終指定に合わせ、4mの試作から胴体を拡大せず尾を2m延ばした。高さ約2.06m、幅約2.65m。小さな退化した後ろ脚を残し、大きな前腕と尾で進む。

**突進の距離延長：** 最新の上限は約40.6m（直前の約13.5mの3倍）、継続1.842秒、最高22.5m/s。縄張りの境界と障害物・人物への接触で停止する。

**突進の停止条件：** 上限まで毎回走らず、プレイヤーの現在位置を通り過ぎたら220msで減速して停止する。前方へ逃げる相手には上限内で突進を続ける。横に避けた相手へ急旋回しない。

## 遊び方と仕様

中心 `(95, 110)`、半径26mの縄張り。周囲32mの木・岩を間引き、草は疎らにした。近くの地図には紫色の縄張りを表示する。

前方約144度・23m以内、遮蔽物なしで発見する。未発見の背後の人物には反応しない。発見後は追跡し、対象が縄張りを出ると攻撃も中止して元の位置へ歩いて戻る。帰還中には新たな追跡を始めない。

体力300。尾を左右に振る700msの予備動作後、5.15m/sで最大2.4秒突進する。大猿の走行5.4m/sより少し遅い。通常の追走は4.9m/s、帰還は1.35m/s。前腕は交互に地面を押し、持ち上げて回す。後ろ脚には歩行周期を付けていない。

| 攻撃 | 時間と範囲 | ダメージ |
| --- | --- | --- |
| 突進 | 向きを固定。移動中の前方の接触を細かく検査 | 25 |
| 噛みつき | 1秒、500msで前方へ判定 | 22 |
| 尾の回転 | 450ms予備動作後、850msで一周。体の原点から4.35m | 20 |

一つの攻撃では同じ人物へ一度だけ命中。距離・向き・遮蔽・縄張り・保護状態はサーバーで判定する。胴体の移動衝突は半径2.1mの円で、尾は攻撃範囲として扱う。全形状の剛体衝突ではない。死亡動作1.6秒の後、60秒で復活。元の位置に人物等がいる間は待つ。既存の回復・持ち物の扱いを継続する。

保存には体力を残すが、途中の攻撃・対象・経路を復帰させず、帰還から再開する。旧保存にも新しい敵を補う。

## 制作

支給原本 → built-in imagegenで単体の制作参照 → ローカルTRELLIS-2（1024、seed42）→ 元メッシュの軽量化・尾の補修と延長 → 専用リグ。可視プリミティブによる代用なし。採用面は67,223三角形、20骨（尾7本）、9クリップ、14,805,624 bytes。採用revisionは配信の `asset.json` と `adoption.json` に記録する。

原本・採用参照・conditioning・dense・不採用の参照と全制作版を `output/model-generation/models/violet-behemoth/` に保持。大きなdenseとBlender作業ファイルはGit対象外のローカル制作物。`source/`、`workflow/`、`production.json` は追跡可能な手順・参照・SHAの記録。

参照v1は後ろ脚が発達していたため不採用。尾の形状を修正したlow-poly r04を4m試作とし、r05で尾のみ延長。rig r01は変形検査不合格、r02は倒れる最後の姿勢を見直し、r03で横倒れへ修正した。r03の表面・材質と死亡以外の8クリップはr02と同じデータであることを独立照合する。
