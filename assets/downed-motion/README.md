# 膝から崩れ落ちるモーション

2026-09-09。全7外見の現行GLBに1.8秒の `Downed` を追加し、通常版へ反映した。

0.2秒までに膝が折れ、0.65秒で両膝をつく。0.86秒まで上体の重さが前へ移り、腕・胸が地面へ倒れて1.8秒で静止する。砂耳の魔法使いの尾も横へ落とす。倒れた終端をサーバーが回復させるまで保つ。

致命傷の `hurtAt` から経過時刻を計算し、遅れて読み込まれたキャラクターも現在の姿勢へシークする。回復場所が空くまで待機時間が延長されても開始時刻をずらさない。歩行・走行・攻撃・ジャンプ・乗り姿勢から移行でき、回復後は通常動作へ戻る。元の4秒の回復時間、元気、持ち物、判定、移動速度は変更していない。

- 手作業で設計した骨格アニメーション。実写の抽出や実行時の物理演算ではない。
- 60Hzで書き出し、各モデルの変形後の全表面から平面への接地を調整した。骨格の長さを変えず、従来のメッシュ・スキン・テクスチャ・材質・元の全クリップとバイナリ部分を保持した。
- 元GLBは元URLへ残し、`model-downed-r01.glb` を別素材として採用。採用SHAは [adoption.json](adoption.json)、元のマニフェストは `source-manifests/`。
