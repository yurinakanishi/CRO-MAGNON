# PS4コントローラー操作

2026-09-09のローカル版。DUALSHOCK 4をUSBまたはBluetoothで端末に接続し、ゲーム画面を開いてボタンを一度押す。ブラウザーが標準配列として認識したコントローラーを使う。HTTPSまたはlocalhostで開き、認識されない場合はChrome / Edgeで接続を確認する。ゲーム内「遊びかた」に接続状態を表示する。

| 操作 | 動作 |
| --- | --- |
| 左スティック | 浅く倒すと歩く、深く倒すと走る。カメラに沿う方向へ移動 |
| 右スティック | カメラ回転。メニュー内は上下スクロール |
| × | 採集・調べる・近くのアクション |
| □ / R2 | 現在の向きに刀・魔法・槍で攻撃。1回押すごとに1回 |
| L2 | ジャンプ。歩行・走行中も使用でき、着地後に離して押すともう一度。騎乗・乗船中は使用不可 |
| △ | 近くの船・マンモスに乗る／降りる。乗れる時に案内を表示。自分で近づき、押した時だけ乗車 |
| ○ | 作業・調理を中止 |
| OPTIONS / 十字キー↓ | 旅のメニュー |
| 十字キー↑ / タッチパッド押下 / SHARE | 世界地図 |
| 十字キー← / → | もちもの / 探索手帳 |
| L1 / R1 | カメラを遠く / 近く |
| R3 | TPS視点を戻す |

メニュー内では十字キーか左スティックで項目を選び、右側の4ボタン（×・○・□・△）のどれでも決定する。戻るときは画面内の「戻る」ボタンを選んで決定する。ウィンドウの「戻る」は右上に表示し、説明をスクロールしても残す。地図の場所などの選択欄は左右で切り替える。名前・チャットはキーボードで入力する。ゲームは共有ワールドのため、メニューを開いても他の人物や敵の時間は進む。

左スティックのデッドゾーンは16%。走行開始は傾き78%以上、歩行へ戻る境界は68%未満。境界付近の揺れによる頻繁な切り替えを避ける。傾きの大きさを移動速度に反映し、斜め入力は最大1に正規化する。スティックの2回倒し・L3は走行条件にしない。キーボードの走行切替はスティックに影響しない。同時使用時はキーボード移動が優先。

右スティックは18%のデッドゾーン。カメラ速度はフレーム間隔に合わせ、上下角度は既存カメラと同じ制限を使う。

切断・画面離脱・チャット入力・メニュー・再接続・倒された後の復帰では、入力を一度ニュートラルに戻す。押しっぱなしの操作を別画面の決定や攻撃へ持ち越さない。毎フレーム新しいGamepad状態を読み、複数接続時は選択済みの1台を継続する。標準配列でない機器のボタン番号は推測しない。

移動は既存のサーバーの速度・当たり判定を使い、採集・戦闘・騎乗・船・製作も既存アクションへ渡す。モデル、保存形式、接続上限、公開版の契約や料金の変更はない。

仕様参照: [MDN: Using the Gamepad API](https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API/Using_the_Gamepad_API)、[W3C: Standard Gamepad mapping](https://w3c.github.io/gamepad/#remapping)。Context7の `/mdn/content` でも仕様を確認した。

検証結果は[gamepad-qa.json](gamepad-qa.json)。実Chromeとローカルサーバーを動かし、`navigator.getGamepads()`の値だけを模擬している。実物のDUALSHOCK 4、USB/Bluetoothごとの実機接続、PS4本体のブラウザー、物理スマートフォンは未検証。PS4本体用アプリの制作ではない。

## タイトル画面とメニュー（2026-09-08）

タイトル画面・旅支度・「旅のはじめに」もダイアログと同じ操作です。十字キーか左スティックで項目を選び、×・○・□・△のどれでも決定します。旅支度には既存の「戻る」、ガイドには旅支度への「戻る」を表示します。ゲーム中の OPTIONS はポーズメニューを開き、設定（環境音・全画面・視点）とタイトルへ戻るもここから選べます。OPTIONSでウィンドウを閉じるショートカットも使えます。複数の決定ボタンを同時に押しても決定は1回だけです。

4ボタンの変更の検証は [gamepad-menu-qa.json](gamepad-menu-qa.json)。再現コマンドは `node scripts/qa-gamepad-menus.mjs`。専用サーバーと実Chromeで入力だけを模擬し、タイトルからの開始、画面内の戻る、ガイドの往復、押しっぱなしによる誤操作の防止、小さい画面での表示を確認します。

## 配置に沿う選択（2026-09-09）

タイトル・旅支度・ガイド・ダイアログでは、十字キーと左スティックの押した方向にある項目を選びます。二列の「もちもの・道具」から下は「探索手帳」、右は「世界地図」です。狭い画面で一列になると、その配置に従います。端では止まり、別の行や先頭へ折り返しません。文字の長さで隣の項目の高さが変わっても、下で同じ行の右へ移りません。矢印キーとWASDも同じ配置を使います。文字入力と選択欄のキーボード編集はブラウザー標準の動作です。Tabでも項目を移動できます。

選択した項目までスクロールし、右上の「戻る」を保持します。決定4ボタンと、選択欄の左右切替は従来どおりです。キャラクター選択はラジオボタンを含むカード全体の位置で判断します。

現在の再現は `node scripts/qa-menu-directions.mjs`（既定は分離ビルド `output/menu-navigation/preview/dist/`）。既に起動中の通常版を確認する場合は `GAME_QA_URL=http://localhost:3000/` を指定します。旧 `qa-gamepad-menus.mjs` は2026-09-08の順送り操作の検証記録です。

関連22テスト、strictを含む分離ビルドと作業ツリーの型検査、依存境界、JS構文を確認。実Chromeで1440×900／390×844／844×390のタイトル・キャラクター選択・ガイド・ポーズメニュー・もちもの・戻る・押しっぱなし・再読込を確認しました。証拠は `output/playwright/menu-directions-20260909/`、通常版は同フォルダーの `local/`。Gamepad API入力と、各検査の開始位置へのDOMフォーカスは模擬で、物理コントローラーは未検証です。

通常3000番にはメニューのクラス・方向判定・案内文だけを反映し、サーバーを再起動していません。分離中のジャンプ等の機能を通常版へまとめて反映せず、既存のガイド・ゲーム状態・サーバーを保持しました。展示LANパッケージとPC2、他の分離プレビューは今回更新していません。

自動接近・クリック移動・目的地移動ボタン・遠征は削除。徒歩・騎乗・操船は方向入力で行います。マンモスの距離・空席・遮蔽・生存・攻撃／被弾待ちを確認して△の乗車案内を出し、押した時にサーバーが再確認します。
