# 大猿の歩幅・速度と肩乗り

2026-09-09、ユーザー指定で実装。通常版は http://localhost:3000/。

## 操作

- 巨腕の大猿の歩行は1.8m/s、走行は5.4m/s（従来の2倍）。歩行の一周期の歩幅は0.662→1.026m、走行は1.372→1.783m。足運びと速度に合わせて再生周期を調整する。
- 大猿と担げるキャラクターが近くで止まると、大猿側に「（相手のプレイヤー名）を担ぐ」。R／△／画面ボタンで誘う。現在、担げるのは砂耳の魔法使い。
- 魔法使い側が「肩に乗る」で応じると、大猿の左肩に座る。「断る」も選べる。誘いは15秒で終了し、移動・離れる操作でも取り消される。
- 大猿はそのまま歩行・走行できる。魔法使いの移動入力は担ぎ手へ伝わらない。どちらからでもR／△／画面ボタンで地面に降りる。
- 攻撃・ジャンプ・作業・別の乗り物・交換は、降りてから。安全な降車位置がなければ肩に残り、大猿が開けた場所へ移動する。被弾・回復待ち・切断で解除し、保存へ関係を持ち越さない。
