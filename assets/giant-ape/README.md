# 巨腕の大猿

後続更新: 歩幅拡大・移動速度2倍・魔法使いの肩乗りを実装済み。現行はrevision-13。詳細は `../shoulder-carry/README.md`。以下は初回採用時の記録。

候補04「赤毛の旅仲間」を基に、ユーザー承認の名称「巨腕の大猿（きょわんのおおざる）」で追加。旅支度のキャラクター選択から使える7番目の外見。身長2m、赤茶の毛、大きな腹、長く太い腕を持つ。

## ゲームでの動作

移動・走行・ジャンプ・採集・製作・受け渡し・食事・手振りと既存の乗降に対応。攻撃は大きな手で打つ（F／画面の攻撃）。身長と幅に合わせ、カメラ注視点1.55m、衝突半径0.76m、歩行0.9m/s・走行2.7m/s。打撃は25ダメージ、開始400ms後の判定、1000ms間隔。武器更新で槍へ変化しない。

座る・座位・立つを含む12クリップをGLBへ収録。既存の砂耳の魔法使い（0.78m）との座面比較は同一縮尺で実施した。これは寸法と姿勢の確認であり、プレイヤー同士の膝乗り操作は未実装。

## 制作と採用

ローカルTRELLIS-2、1024、seed 42。候補04と単体立ち姿、conditioning、dense、軽量化、全リグ版を `output/model-generation/models/giant-ape/` に保持。独自の22骨格とスキン、実寸の足裏による歩行調整を使用した。可視プリミティブへの置き換えなし。原材質の粗さを保持し、毛・皮を非金属に修正。色画像のJPEG圧縮はPSNR 43.34dB。

採用は `work/rig/revision-12/candidate.glb`、106357三角形、16301868バイト。SHA-256: `0192c6868abd8be07451340326bcb229ce45755693962fb417fd55dbab53e290`。配信先は `public/models/giant-ape/model.glb`。原画像、過去版と既存モデルは保持した。毛の重なりや開いた面を含み、3D印刷用の閉じた形状とはしていない。

## 検証

- 全369テスト、型検査、JS構文、依存境界が通過。舟の足元は幅の広い骨格だけを調整し、全7外見の既存制約を検査。
- 全12クリップを60Hzで独立スキン計算し、地面からの最低位置、変形、ループの閉じ方、in-placeを検査。
- 6方向×5時刻×12クリップの360画像と12動画を生成。全360画像を一覧で、選択した画像を原寸で、動作を実ブラウザーで確認した。全動画の通覧を意味しない。
- 実ブラウザー2画面＋通信3人。5人の描画、歩行・走行・ジャンプ・打撃・手振り・マンモス騎乗中の停止／移動・降車を両画面で観測。プロフィール、連続キー入力、騎乗前の位置とマンモス待機は明示的な準備値。エラー0。
- 実iframeの390×844／844×390で選択・開始・ジャンプ・打撃を確認。物理タッチ端末や物理コントローラーの検証ではない。
- 配信マニフェスト参照56GLBのSHAと容量を照合。旧モデルの制作元不足で既存の全制作系統検査は未完走。今回の大猿の制作系統は保存済み。

全地形での接触、物理端末・コントローラー、長時間・大人数負荷、常時60FPSは未検証。公開デプロイ、展示パッケージ更新、Meshmell投稿、古い保存の再適用は行っていない。
