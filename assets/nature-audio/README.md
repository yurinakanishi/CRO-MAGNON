# Nature audio sources

The runtime uses only `public/audio/nature/` (51 MP3 files, 6,550,373 bytes).
See its `manifest.json` for original file SHA-256 hashes, source pages, authors, CC0
licenses, extraction intervals, processing, output hashes and exact sizes.

`source/` preserves the original first-version sources, including Fantozzi footsteps.
`quality-source/` adds the explicitly licensed CC0 field recordings and VSCO 2 CE
instrument samples (pinned Git commit, download URLs, author and SHA in sources.json).
`quality-masters/` contains the lossless PCM masters, never shipped to the game.

`foley-source/` preserves CC0 cloth, impacts, snow, water, bamboo swishes and cat hiss,
plus primary-source licence evidence and hashes. `fetch-nature-foley.mjs` retrieves
and safely extracts those originals. The cat recording uses its public HQ MP3;
the original WAV requires login. The old `source/kenney-impact.zip` candidate is
not a valid archive; the new verified original is `foley-source/impact.zip`.

`node scripts/prepare-nature-audio.mjs` runs `prepare-nature-quality.py` then
`prepare-nature-foley.py`, sharing `nature_audio_mastering.py`.
It requires Python/numpy and FFmpeg (set PYTHON / FFMPEG as needed), only reads
local sources, and never fetches files or touches game state. The separate
`fetch-nature-quality.mjs` explicitly downloads the listed public CC0 originals.

Mastering preserves 44.1 kHz stereo for wind, river, shore, rain and music; localized
fire/torch, birds and drops are mono. Continuous recordings use 2–4 second
equal-power crossfades. Static loudness gains preserve dynamics, with headroom
protection; no per-frame automatic normalization. MP3 VBR q2 has matching decoded
durations and bounded loop seams in real Chrome. Decoded buffers use approximately
112.4 MiB at the requested 44.1 kHz; the 48 kHz bound is 122.4 MiB.

`source/kenney-impact.zip` is an unused research candidate and is never packaged.
The three original 48-second compositions use recorded VSCO flute and harp
multisamples, with small tuning correction, near-pitch sample selection, natural
attacks, releases, breath gaps and dark reverb. No prerecorded third-party song or
music generation service is used. Rain and water drops now use licensed source
audio instead of simple synthetic noise/tones. Only the acoustic reverb impulse
is synthesized at runtime, in `src/nature-audio-design.ts`.

The user initially removed all footsteps, action cues, stingers and UI sounds,
then explicitly requested improved versions back in the game. Revision 3 adds
37 short files covering all 17 former categories, independent effects volume
(default 50%), no immediate variant repetition, and bounded event/voice counts.
Wind is now -38 LUFS (was -32), with softer high frequencies; river is -29 (was -25).
Together with gentler runtime gains these are about 8 dB / 6 dB quieter at reference
conditions. The other twelve previous assets remain byte-identical.

The previous synthesis source and six footstep WAVs are retained only for audition
in `removed-20261006/`, outside every distribution. The review page and all 30
playable historical examples are in `output/nature-audio-review-20261006/index.html`.
`before-quality-20261006/` separately preserves the version before quality work.
`before-soften-20261006/` preserves revision 2 and its louder comparison gallery.
The latest gallery is `output/nature-audio-quality-20261006/index.html` (72 players),
generated by `prepare-nature-restored-review.py`. All current previews bake in the
actual default ambience 70% / music 30% / effects 50% gains, without loudness boosting.
Wind/river compare to revision 2 under matched conditions. Old effects are explicitly
labelled historical timbre references. No automatic playback.
