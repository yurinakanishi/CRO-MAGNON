# 垂れ耳の魔法使いの交換検証

対象はダウンロードの最新画像に写る左の主役。右下の相棒は制作対象に含めない。元画像、imagegenで整えた参照画像、TRELLISのdense、軽量化とリグの各revisionを区別して保存する。

- 元画像との顔、垂れ耳、体型、赤と生成りの服、革装備の一致を確認する。
- denseと配信予定GLBの正面、背面、左右、斜め、上下を同条件で比較する。clay表示でも輪郭と表面を確認する。
- 最終GLBを再読込し、待機、歩行、走行、採集、制作、受渡、食事、挨拶、魔法の9動作を検証する。骨、最大4ウェイト、ループ継ぎ目、接地、裾と耳の変形を測定する。
- デスクトップで種族選択、通常移動、自由魔法、採集、騎乗と降車を操作する。カメラ、装備、UIの呼称と肖像を確認する。
- 2つの実ブラウザーと3つの通信参加者で同時5人の描画と動作同期を確認する。
- 390×844で選択、移動、魔法と画面の収まりを確認する。
- 対象がいない自由攻撃、再読込後の同じプロフィールの復帰を追加確認する。
- 配信GLBのSHA、全素材、既存テスト、構文検査を実施する。既存のこぐま制作物と旧配信ファイルは保存する。

生成、採用、ゲームQAをそれぞれ記録し、確認前に成功としない。性能値は今回の実測条件とともに保存する。
