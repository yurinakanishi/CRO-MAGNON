# 世界の探索コンテンツ拡張 — 2026-09-08

ブランチ：`codex/imp-world-expansion`。ユーザーの「山、谷、さまざまな地域、裏世界などコンテンツを充実させる」という依頼で実装。

## 遊び方

地図の下の「探索手帳」、または左の「旅の手帳」から地域を選ぶ。地上の5地域は「この地域へ遠征」で到着し、「次の目標へ」で実際に道を走る。道標は3.4 m以内で自動記録。採集は現地の資源から行う。達成後はその地域の野営地に戻って報告する。

| 地域 | 景観 | 依頼 |
| --- | --- | --- |
| 天風の山道 | 雪を頂く岩山、山裾の通路 | 道標3つ・石4個 |
| こだまの峡谷 | 黄褐色の岩壁、峡谷の通路 | 道標3つ・木材4個 |
| 星影の石の森 | 針葉樹と苔色の巨石、青い裂け目 | 道標3つ・番人1体 |
| 琥珀のオアシス | 砂岩、浅い泉、ベリーの茂み | 道標3つ・ベリー3個 |
| 蒼氷の回廊 | 青い氷壁の間の通路 | 道標3つ・石5個・番人1体 |
| 裏世界・影の庭 | 紫の空と黒い地面、石柱と浮遊光 | 道標3つ・異なる番人2体 |

地上の依頼を3つ報告すると、石の森の「星の裂け目」でEを押して影の庭へ入れる。影の庭の野営地にある裂け目、または手帳の「地上へ戻る」で帰還する。各地の焚き火は調理に使え、近くで「休息」により元気35回復（間隔20秒、敵の近くでは不可）。依頼の報酬は食料・資材・旅の証。影の庭を報告すると手帳に称号「境界を渡る者」を表示する。

番人の討伐時、24 m以内の倒れていない徒歩の仲間にも達成を記録する。同じ番人を再度倒しても同じ個人の依頼に重複加算しない。報酬は個人ごと・地域ごとに1回。持ち物が満杯なら何も消費せず、空きを作ってから受け取れる。

## 実装範囲と素材

- 既存の4,096 × 2,048 mの大陸・2 m海岸格子を保持。6地域は十分な陸地のある場所へ配置した創作の探索区画。影の庭は同じ共有ワールド内の遠い区画を幻想的に演出したもので、別サーバー・別インスタンス・精密な地下洞窟シミュレーションではない。
- 山の形は採用済み`volcanic-cone`を雪・岩色の材質で共有。山の斜面そのものは固体で、歩行経路は山裾と氷壁の間を通る。自由な山登りや高さの異なる橋は追加していない。
- 地域ランドマーク66配置、木・野営地・道標・茂み48配置、採集資源18か所、既存`crow-shaman`の番人4体を追加。敵の形と動作は既存GLBのまま、HP75／100／125に地域差を付けた。
- 新規GLBは0。全32モデル・47配信GLBのSHA-256を照合。山、岩、氷壁、玄武岩、人物、植物、テント、水は既存のTRELLIS由来GLBを使用する。既存モデルやリグ・クリップ・テクスチャを上書きしない。
- 地域材質は同一素材・同一処理の間で共有し、元のgeometry・textureを共有。未使用のランドマーク材質は12秒後に破棄する。道標と裂け目の光は固定396点、水の波紋と天候はランタイム効果。
- 手帳の進行、解放、採集、討伐、報酬、帰還先はサーバーが決定。クライアントから報酬量や任意の転移座標は受け取らない。通常の最大5人を維持。
- 探索進行は既存の再接続セッションとワールドのexport/importに含む。古い保存には新しい資源と番人を追加し、既存の持ち物・資源・拠点を保持する。import時に元の保存オブジェクトへソケットを付けたり書き換えたりしないよう修正。
- 公開サイトへのデプロイ、Cloudflareの契約・料金変更は今回の範囲に含まない。

## 検証

`delivery-qa.json` は47配信GLBの直接検証。従来の `verify-world-assets.mjs` は、元々ローカル生成履歴の `output/model-generation/models/neanderthal-hunter/qa/adoption-review.json` が欠けているため実行を完了できない。今回、その履歴を捏造・再生成していない。

`tests/adventures.test.mjs` は全経路、道標・遮蔽物、地域採集、報酬の原子性と重複防止、裂け目の条件・混雑・帰還、実攻撃・魔法による協力討伐、休息、旧保存への追加・再接続、材質と形状の共有を検証する。

ゲーム検証：`scripts/qa-adventures.mjs`。2つの実Chrome画面と3つのWebSocket参加者を使い、位置・HP・依頼を直接書き換えず、遠征と通常の移動・採集・攻撃・報告で巡回する。画面と結果は`game-qa/`にrevision別で保存する。`scripts/qa-adventure-views.mjs`は、外観と小さな画面の検証用にのみ解放済みのサーバー側テスト状態を用いる（`visual-qa/`）。これを通常プレイの達成結果に混ぜない。

初回は手帳ボタンと狩猟カードの重なりを発見し修正。r02は山道・峡谷・オアシス・石の森の依頼を完了したが、回復せずに連戦した検証プレイヤーが氷の番人に倒された。持ち物と探索記録を保持して開始地点へ戻った。r03は報酬の食料を使い、全6地域の依頼をクノイチで達成。報告直後の帰還が共通450 ms制限に拒否される不具合を発見したため、裂け目は独自の3秒制限で検証するよう修正し、同じメッセージハンドラーを通す回帰テストを追加。

最終の `game-qa/r04/report.json` は通過。全6地域・18道標・現地採集・番人4体・全報酬・裂け目の解放と帰還・同じタブの再読み込みを確認した。2つの実Chromeと3つの通信参加者が同じ部屋に入り、地上5地域への5人の到着を確認。1,818回の観測で静物・動的物体の衝突違反0、描画エラー0。地上5地域で記録した描画は46〜60 FPS、地形は最大69区画。390×844の手帳・全体地図・局所地図、844×390の手帳も通過した。

水面はその後に材質だけ調整し、既存水GLBを楕円形の岸で切り抜き、強すぎた波紋を抑えた。`visual-qa/r03/` で実際の泉、影の庭、スマートフォン寸法を確認し、描画エラー・横はみ出し0。地形・衝突・依頼処理はr04から変更していない。

全体は187テスト中186通過。既存の `tests/open-world-restore.test.mjs` は無視対象の `output/open-world-restart/run.mjs` 不在でロード失敗。追加機能・船・復帰・地上遠征・Cloudflareコアの関連24テスト、161 JavaScriptファイルの構文検査は通過。47 GLBもすべて配信SHAと一致した。結果の一覧は `qa-summary.json`。

### 再検証

`node --test tests/adventures.test.mjs`、`node scripts/check-syntax.mjs`、`node scripts/verify-adventure-delivery.mjs`。ブラウザーQAにはChromeとPlaywrightが必要。`PLAYWRIGHT_MODULE` を既存Playwrightの `index.mjs` のfile URLへ指定すると、そのインストールを使える。未指定時はプロジェクトから `playwright` を解決する。ゲームの実行依存には追加していない。`node scripts/qa-adventures.mjs assets/adventure/game-qa/<新しいrevision>` と `node scripts/qa-adventure-views.mjs assets/adventure/visual-qa/<新しいrevision>` を実行する。両方とも一時ポートの独立したサーバー・ブラウザープロフィールで実行し、検証後に閉じる。
