# 住人が採った実を夕食へ

既存8住人が朝と昼に、今暮らしている集落のベリーの茂みへ歩きます。そばで4秒採ると共有資源が1個減り、住人が1個持ち運びます。夕べの炉へ戻ると既存の住人用の夕食に加え、従来の順番で食べます。計画は [RESIDENT_FORAGING_PLAN.md](../../RESIDENT_FORAGING_PLAN.md)。

## 遊び方

「湾の旅の案内」→「共同の食料置き場」→「住人の夕食」で、食事と採集の記録を確認できます。住人一覧と近くでの会話でも、採った日・運搬中・届けた場所を表示します。住人が実を採りに歩く様子は、各集落の北西の既存の茂みで見られます。

一人一日1個まで、茂みに残り2個以下なら採りません。プレイヤーは従来どおり残りの実も採集できます。国・種族・性別の制限はありません。訪問中の世帯は集い場で採集し、道中や会話を優先します。実を採った後は従来の日課へ戻ります。

食料置き場は共同食料と夕食を合わせて48個です。満杯なら住人は運んだ実を保持し、空きができた夕べに届けます。翌日や旅先にも持ち越し、届けるまでは次の採集をしません。通常の共同食料、プレイヤーの畑・持ち物・採集実績を自動で消費しません。食料不足で衰弱・死亡・旅の停止は起こりません。

## 判定と保存

- 採集元は四集落の既存12茂み。4m以内・遮蔽なし・停止・朝／昼の日課・在庫3個以上をサーバーが確認します。4秒が完了した時だけ1個を減らし、既存の資源再生時刻を更新します。
- 会話・移動・日課の切替・出発は途中の作業を中止します。無人の部屋では途中の時間を消し、時計を飛ばしても過去の日数分を生産しません。
- 運搬は住人ごとに最大1個。夕べの目的地に到着し、実際の大きい炉または小さい炉への見通しがある時に納入します。納入と食事は別の処理で、共同食料へ移した食品には従来の一日3個の受取制限が適用されます。
- 最後に採った日と茂み、運搬中かどうか、届けた日と場所をexport/importと通信へ含めます。途中の作業時間は保存しません。古い保存は未記録を補います。資源と夕食の変更は通常90msを待たずに共有されます。

## 検証

分離ビルドの全335テストが通過しました。新しい11テストで自宅／訪問先の全8人の実際の経路、4秒の完了、残り2個、遮蔽と距離、中断、満杯からの持ち越し、旅先での納入、8人の資源・容量の競合、保存と旧保存、無人・時計の飛びを確認しています。食品・作物・プレイヤー持ち物の保持も検証します。

実Chrome2画面＋通信3人の953観測で衝突違反・ブラウザーエラー0。訪問中の8住人が、二日分の採集と納入・食事を行いました。共通在庫、運搬中の再読込、満杯での保持と通常UIの受取による空き、住人との会話、390×844／844×390、模擬Gamepadの選択保持・スクロール・戻るを確認しました。

訪問状態、住人の開始位置と日別記録、初期資源在庫、第二画面などの近接位置、置き場を満たす焼き根47個、3回の時計変更は明示的な準備値です。採集場所への歩行、4秒の作業、炉への帰還、納入・食事は実時間で行っています。共同のベリー1個は通常の遠征と旅支度の食料から預けました。初日の朝から夕べまでは時計を進めていません。

再現は [scripts/qa-resident-foraging.mjs](../../scripts/qa-resident-foraging.mjs)。専用のQA部屋だけを使うスクリプトです。実行環境はNodeとChrome、既存のPlaywrightです。`GAME_QA_BUILD` で分離済みのdistを指定できます。通常サーバー・利用中の部屋を変更しません。`qa-summary.json`、`journeys.json`、`server-tests.txt` に検証の範囲を保存しています。

## 範囲と創作

採集の規則、時間、ベリーの種類と再生、運搬量、夕食へ届ける手順は創作です。考古学的な収量・栄養・制度の復元ではありません。背景は [WORLD_SETTING_PLAN.md](../../WORLD_SETTING_PLAN.md) を保持します。

39モデル・54GLBのSHAを保持し、新規GLB・依存パッケージは0。既存の採集・歩行・待機動作を再利用し、手に持つ実・籠・食器の可視モデルは追加していません。物理端末・物理コントローラー・大人数負荷・長時間稼働・常時60FPSは未検証です。自動農耕・漁労・狩猟、腐敗、長期栄養収支、人口変化、政治は今後の範囲です。
