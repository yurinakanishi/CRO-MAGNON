## 遊び方

「三つの岸の湾」→「集落の人びと・今日の手伝い」、または ESC / OPTIONS のメニューから開く。集落の炉へ歩き、畑・採集場所・作業場にいる住人を訪ねる。近くにいる仕事・休息中の人には、案内のボタンで現在地のそばまで歩ける。移動中の人は名前を目印に追いかける。近くで E / × を押すと会話が開く。

会話には、その人の暮らしと小さな頼み事がある。必要な材料と受け取るお礼を読んで「材料を渡して手伝う」を選ぶ。どの国・外見のプレイヤーでも、同じ住人の手伝いを一日一回ずつ行える。別の人が済ませても自分の分は残る。材料不足・所持上限・距離不足では材料を失わない。

## 日課と状態

- 現行のゲーム内一日は4分。朝・昼・夕べ・休息を各60秒とし、1 m/sで集落内を歩く。朝は実や薪を選び、昼は畑や道具を手入れし、夕べには炉へ、休息時には天幕の周りへ戻る。独立した季節の長距離移住ではない。
- 既存の陸地・地形・静物・動物・人物の衝突処理を使う。混雑時は経路を探し直す。再読み込みや日課変更で住人を目的地に瞬間移動させない。
- 会話が成立すると最大20秒足を止める。話したプレイヤーが離れる／切断すると日課に戻る。会話は排他的な占有ではなく、ほかのプレイヤーも話せる。住人は攻撃対象にならない。
- 日課の作業は暮らしの演出であり、共有の畑・資源・持ち物を自動消費しない。プレイヤーが選んだ手伝いの受け渡しだけが実際の所持品を変える。
- サーバーが距離3.2 m・遮蔽・作業中・材料・報酬上限99・日別の重複受取を検査する。時刻や報酬のクライアント指定は使わない。
- 住人8人は接続枠に含まれない。既定5人と世界の広さは変更せず、8プレイヤー＋8住人のコアテストを行う。64人負荷を検証した意味ではない。

`gulf.metResidents` と `gulf.residentHelp` は人物ID8件までの個人記録。後者は最後に手伝ったゲーム内の日を保存する。住人の現在地と向きも既存の export/import に含む。古い保存には8人を補完し、会話中の停止は復元しない。既存の再接続猶予とホストごとの保存機構を引き継ぐ。Node版に通常のディスク永続化を追加したものではない。

## 描画と制作

新しいGLB・依存パッケージ・可視プリミティブは0。既存の `CharacterAssets` プロバイダーでgeometry・textureと元の9動作を共有し、住人ごとに骨格とAnimationMixerを持つ。採集・作業には既存のGather / Craftを使い、手に新たな道具の代替形状を足さない。

65 m以内の住人を読み込み、22 m以内に名前を表示する。範囲外では描画と動作更新を止め、12秒後に人物インスタンス・骨格・ラベルを解放する。共有モデルのテンプレートは既存の人物キャッシュに残る。ワールド全体のテンプレートまで毎回解放する実装ではない。

[Three.jsの公式仕様](https://github.com/mrdoob/three.js/blob/dev/examples/jsm/utils/SkeletonUtils.js) に従う既存クローン処理を利用し、[個別骨格の解放](https://github.com/mrdoob/three.js/blob/dev/manual/pages/how-to-dispose-of-objects.html) は共有geometryやtextureを破棄しない。コード上の参照共有と、配信済み38モデル・53GLBのSHA保持を確認した。詳細は [assets-qa.json](assets-qa.json)。

## 根拠と限界

人物名・台詞・国の習わし・日課・通年の住人・毎日のお礼は創作。農耕・国・後代まで暮らすネアンデルタール人は許可済みのファンタジー。[考古学の背景と区別](../../WORLD_SETTING_PLAN.md) を保持する。家族の実際の人口動態、世帯移住、NPCによる食料生産、政治制度を復元したとは扱わない。

検証は [qa-summary.json](qa-summary.json)、再現用は [qa-village-life.mjs](../../scripts/qa-village-life.mjs)。実ブラウザーの準備位置・材料と時計の進行は実際の徒歩や採集から区別して記録する。物理スマートフォン・物理コントローラー・大人数負荷・長期稼働・常時60 FPSは未検証。公開デプロイ・料金変更はこの作業に含めない。
