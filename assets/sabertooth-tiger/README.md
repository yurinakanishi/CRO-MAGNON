# 剣牙の大虎

ユーザー指示「敵のサーベルタイガーつくって。かなりつよいし、動きも早い。ステップとかしてくる。ジャンプ飛びかかりとか。」に基づく敵。全長2.6 m、肩高約1.2 m（頭頂1.65 m）。シベリアの雪原の焚き火の北 `(493, −19)` に1体、縄張り半径24 m。

## 遊び方と仕様

体力340。追走6.2 m/sで大猿の走行5.4 m/sより速く、逃げ切るには縄張りの外へ出るしかない。帰還は1.5 m/s。前方±75度・24 m以内で遮蔽なしに発見し、背後でも7 m以内の足音で気付く。

| 行動 | 時間と範囲 | ダメージ |
| --- | --- | --- |
| 飛びかかり | 3.5〜10 mから。450 msの静止したしゃがみ（被弾で中断）→600 msの跳躍（被弾しても怯まない）→500 msの着地の隙。跳躍の45%以降の体の接触で一度だけ命中。再使用2.6 s | 30 |
| 爪の連撃 | 0.9 m以内。320 msと620 msの前方2振り、それぞれ別の命中判定。2回に1回は後ろへ跳んで離れる | 16＋16 |
| ステップ | 4.2 m以内で自分を向いた突き・斬りの予備動作、または6 m以内に飛んでくる光弾を見ると、攻撃線を横切って3.4 m跳ぶ（左右交互、壁を検査、両側が塞がれば後退）。跳躍中は体を狙えない。再使用1.8 s、直後の飛びかかりは即可 | — |

距離・向き・遮蔽・縄張り・保護状態はサーバーで判定する。対象が縄張りを出ると攻撃を中止して元の位置へ歩いて戻る。死亡動作1.5 s、90 sで復活（元の位置が空くまで待つ）。保存には体力を残し、復帰では攻撃・跳躍中の無敵・回避を解除して帰還から再開する。旧保存にも補う。地図には琥珀色の縄張りと「剣牙の大虎の狩り場」を表示する。

## 制作

このPCには画像生成手段がないため、ユーザー指定でCodex CLIの内蔵 `image_gen`（`gpt-5.6-sol`、reasoning medium）をClaude Codeから固定プロンプト（`source/codex-request.txt`）で実行し、3案を生成。ユーザーが候補01（黄金色・薄い縞）を選択。参照 `output/model-generation/models/sabertooth-tiger/source/original/reference-v1.png`（`source/reference-v1.json` にSHA）。

BiRefNet → ローカルTRELLIS-2（1024、seed 42、535 s、dense 294,342三角形）→ 溶接・浮遊片除去・上限付き平滑化・許容内のQEM（ratio 0.25、72,892三角形、p95偏差1.5 mm・最大5 mm）→ 背中の中心線による剛体ヨーと全長2.6 mへの均一スケール → 四足専用リグ（スキン24関節、顎なし：口は閉じており牙が顎の前に垂れるため）→ 9動作を60 fpsキーで焼き込み。可視形状の追加や代用なし。

足は接地点の最大間隙で前後に分け、脚の中心を薄い帯で上へ辿る。接地中の足は2骨IKで固定し、肩甲骨のスライドで歩幅の両端の届きを補う（接地足の不足は歩行・走行で≤0.09 m、他は0）。腹と胸の中心線は胴に戻して左右の脚に裂かれないようにし、毛の房は近接する別シェルも含めて平滑化する。最下点が2 mmより沈む場合は体を持ち上げる。

動作（全てin-place、水平移動はサーバー）: Idle 3 s、Walk 0.8 s（1.3 m/s）、Run 0.4 s（6.2 m/s回旋ギャロップ）、Alert 0.6 s咆哮、Pounce 1.55 s、Step 0.35 s、Attack 1.0 s（2振り）、Hit 0.3 s、Death 1.5 s横倒れ。

採用: rig revision 11、SHA `6c4c5301071c1d69add3b357a14b8ba6af62a47a79089657928ab6424bde045d`、20,120,956 bytes。revision 10との差はStepの長さ（0.367→0.35 s、サーバーの `stepMs` と一致させる）のみ。低ポリはrevision 02（01は対称性フィットが片寄った姿勢に引きずられたため、背中の中心線で整列し直した）。
