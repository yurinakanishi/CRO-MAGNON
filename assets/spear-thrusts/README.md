# 両手で構え、左足を踏み込む槍の突き

2026-09-12、revision-02 を人間4体に採用。木槍・黒曜石の槍とも同じ動作を使う。

## 追補：握る位置を根元へ移動

ユーザーの「もっと槍の根元を持つべき」に合わせ、攻撃の構えでは両手を柄の後ろ側へ50 cm寄せた。右手は槍のお尻から約21 cm（以前は約71 cm）、左手は約53〜57 cm。前へ出る槍が50 cm長くなる。人物の踏み込みと手の動きは採用済みのままで、GLB・SHA・配信URLの変更はない。

`orientSpear()` は現在の攻撃時刻を受け取り、最初の140 msで槍を手の中で前へ滑らせ、520〜700 msで普段の持ち方へ戻す。右手の骨を親としたまま、槍の向きに沿って位置をずらすので、左右の手は同じ柄の上に残る。待機・歩行・走行では元の握り位置。

この追補ではビルド、対象10テスト、284 JS構文・依存境界・変更ファイルの書式を確認。テストは両方の実槍GLBの外形から、4体×4方向で握り位置がお尻から上記の範囲に入ることと、待機時の取り付け位置への復帰を検査する。実Chromeの5人接続、4体×2武器、相手画面、歩走からの攻撃・ジャンプ・再読込のQAも再実行して合格。`rear-grip-game-qa.json`、`rear-grip-delivery.json` に記録。

新しい5方向の画像と30 fps動画は `output/playwright/spear-thrusts/revision-02/rear-grip/`、ゲーム内の命中時画像とフレーム記録は `output/playwright/spear-thrusts/game/rear-grip/`。再現時はQA・動画スクリプトに環境変数 `SPEAR_REVIEW_VARIANT=rear-grip` を渡す。通常3000番の新しいJSと4体の同一SHAを確認済み。以下の数値検査と採用表は人物のクリップrevision-02の記録。

ユーザー指定は「右利きなら両手で槍を持ち、左足を前に出しながら槍を前に突き出す」。この指示を元に手作業で動作を設計し、既存の腕・脚の骨長に合わせたIKで焼き込んだ。実写やモーションキャプチャから抽出した動作ではない。

## 動作と取り付け

- 0〜140 ms：右手で持った槍を腰より上の構えへ下ろし、左手を前の柄に添える。
- 160〜333 ms：右足で支え、左足を前に出す。骨盤と胸を前へ送り、左膝を曲げて踏み込みながら両手で突く。
- 333 ms：槍を水平にした最大伸長。既存の命中時刻 `impactMs: 333` と一致する。
- 390〜700 ms：槍を引き、左足を戻して通常の持ち方へ戻る。既存の攻撃時間700 msと一致する。

`scripts/build-spear-thrusts.mjs` は120 Hz＋333 msの計86キーを作成する。前後の手の間隔は身長の20%。両手の位置を同じ量だけ補正して両腕が届く構えにし、膝と肘の曲がる側を指定する。足裏は実スキンの底面サンプルで接地を補正する。

右手の既存 `Grip.R` に槍を取り付ける。新しいクリップは手首の向きも含むので、`src/spear-pose.ts` と `src/world3d.ts` は `spearThrust.attachment: authored-grip` のとき、その向きを保持する。これで左手の `Grip.L` を槍の柄が通り、構え・戻し・動作混合でも右手と槍が一緒に動く。従来モデルの前向き補正は互換用に残る。

槍の形状、両手の元の指形状、人物のメッシュ・材質・骨構造・ウェイトは変更していない。指の個別リグはない。身体の中心の移動はクリップ内の骨盤だけで、`Root` とサーバーの位置は移動しない。攻撃のダメージ・届く距離・再使用時間も元のまま。
