# キャラクターのジャンプ

全6外見で **Space / 画面の「ジャンプ」 / 標準Gamepad L2**。
走行・歩行・地面クリックの経路移動を続けながら跳べます。
既存の×・○・□・△、L1 / R1、R3の割当は維持します。

サーバーが開始時刻を確定し、1m・720msの弧を両画面で描画します。
着地後100msで再使用でき、空中の連打や押しっぱなしでは続けて跳びません。
既存の骨格を使って脚を曲げ、着地後に歩行・走行・攻撃へ戻します。
通常の水平衝突と地形を使うので、壁や海岸は飛び越えません。
騎乗・乗船・回復待ち・攻撃動作中は跳べません。

跳ぶと釣り・採集作業・調理と交換を中止し、完成前の材料を保持します。
空中では別作業、攻撃、遠征、交換開始を待ちます。メニューを開いても着地まで進みます。
被弾判定は既存どおりで、回避の無敵時間や落下ダメージは追加していません。
ジャンプ途中はexport/importや再接続へ持ち越しません。旧保存は地面から復帰します。
