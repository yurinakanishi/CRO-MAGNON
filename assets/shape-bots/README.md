# 追加の4種類のbot

添付 `Screenshot_20261001-204133.png` の4体を、既存5種類と一緒に持つ・投げる・呼び戻せる仲間として制作・採用した。2026-10-02に通常のローカル3000番へ反映。原画像を無加工で `source/user-reference.png` に保持。既存91GLBと3部屋・5人分の保存内容を保持した。

| 種類 | モデルキー | 特徴 |
| --- | --- | --- |
| ベレーbot | `orb-bot-beret` | 青い二段の丸み、黒いベレー帽、縦長の目 |
| かえるbot | `orb-bot-frog` | 黄緑の体、飛び出した2つの白黒の目 |
| さんかくbot | `orb-bot-triangle` | 黄色の角丸三角、丸眼鏡、閉じた目 |
| ハートbot | `orb-bot-heart` | 濃いピンクのハート、丸いサングラス |

各Candidate 1。参照をbuilt-in imagegenで作成し、ローカルTRELLIS-2 v0.8.1で個別に復元。形状を測って軽量化し、Root/Bodyの2骨、7クリップ、元の骨・材質を共有する遠景を用意する。制作参照の色へ補正したalbedoと補正前のdenseを両方保持。見えない背面・厚みは復元による推定。

ゲームの最新操作は **Cを押すたびに次の1匹を投げる、Zで種類、Qで集合**。コントローラーではL3で1匹ずつ投げる、十字↑で集合、種類はメニュー「botたち」。投げた場所で待ち、呼ぶと戻る。各参加者に9匹、5人で45匹。持ち物へ加えるアイテムではなく、接続中の仲間。[2026-10-02の変更・検証](../../docs/bot-volley-2026-10-02.md) を参照。

最終版はベレーr03・かえるr01・さんかくr06・ハートr02。`revisions.json` と `reviews/` に採用状態、[制作記録](../../docs/shape-bots-2026-10-01.md) に実測値・不採用の理由を記録。全781テスト・58モデル素材検証、実Chrome2画面＋通信3人で45匹の投擲と帰還・全9人物・再参加、3画面寸法33ボタンを確認した。

最終採用は `adoption.json`、通常3000番への照合は `local-delivery.json`、正常終了・再起動と保存は `local-restart.json`。正本ライブラリの全ファイルを読み戻した照合結果は `archive.json` に記録する。物理端末・実パッド・長時間稼働は未検証。公開デプロイ・展示配布・Git操作なし。

元の投擲・帰還の調査と実装は [前の5種類の記録](../../docs/orb-bots-2026-10-01.md) を参照。
