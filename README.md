# CRO-MAGNON

TypeScript開発・ビルド手順と責務の分離は [ARCHITECTURE.md](ARCHITECTURE.md) を参照してください。`npm start` / `npm test` は先にビルドし、`npm run dev` はTypeScriptとCSSを監視します。直接 `node server.mjs` を使う場合は先に `npm run build` を実行してください。

クロマニョン人とネアンデルタール人が、草原・雪原・氷原・火山・砂漠を探索する3Dブラウザゲームの試作です。約5万年前の地球の大陸を近似した4,096 × 2,048 mの世界を探索できます。猫耳の女性クノイチと、小さなこぐまの魔法使いも選択できます。キャラクターの後ろ・肩越しから見るTPS視点で探索し、1部屋あたり最大5人で、採集・物々交換・チャット・野営地づくり、マンモスの狩猟と肉の採取を共有します。

左下のプロフィールからキャラクターを変更できます。クノイチは刀、こぐまは両手から放つ光の魔法、人間は槍で攻撃します。いずれも **F / 5 / 攻撃ボタン** で、相手がいない場所でも発動できます。プロフィール変更で再参加すると個人の持ち物はリセットされます。

マンモスには **R /「近づいて乗る」** で乗れます。移動する相手を追いかけ、横まで届くと乗ります。1頭に1人、WASD・地面クリックで移動、Shift・走行ボタンで走行、Rで降車。接近中はWASDやRで中止できます。攻撃・採集・食事は降りてから。マンモスが通れない狭い道では、降りて進んでください。

砂漠にはサボテン、火山には柱状玄武岩を新しく制作して配置しました。共通の木や岩、雪・砂・灰の地域表現も保持し、同じ種類のモデルは形状とテクスチャを共有します。[地域の比較画面](http://localhost:3000/biome-review.html)から新作モデルも確認できます。[制作・検証記録](assets/region-specific-game-qa.json)は全31モデル、135テスト、5人接続、スマートフォン表示を含みます。

## 起動

2026-09-07の全体調査で、入力中の意図しない移動、スマートフォンの操作欄、刀の接近距離、採集・調理の競合、地域移動後の地面クリック、通信の取りこぼし、短時間の切断からの復帰などを修正しました。152テストと全31モデルの検証、最大5人の接続を確認しています。[修正内容と検証範囲](assets/bug-audit.md)を参照してください。

Node.js 22以上と、WebGL 2対応ブラウザが必要です。プロジェクトのフォルダーで実行します。

```sh
npm install
npm start
```

[http://localhost:3000](http://localhost:3000) をブラウザで開きます。停止はターミナルで `Ctrl+C`。開発時は `npm run dev` でサーバーの変更を監視できます。

## 5人で遊ぶ

1. サーバーを起動したPCでゲームを開き、名前・キャラクター・部屋のコードを設定します。人間は女性・男性も選べます。
2. 「仲間を招待する」から招待リンクをコピーします。
3. 同じWi-Fi・LANにいる仲間にリンクを渡し、同じ部屋に参加してもらいます。

招待リンクはサーバーPCのLANアドレスを使用します。複数のネットワーク接続がある場合は、仲間から到達できるアドレスを選んでください。接続できないときは、サーバーPCのファイアウォールでNode.jsまたはTCPポート3000の許可が必要になることがあります。サーバーPCは起動したままにします。

インターネットへの公開はまだ行っていません。別のネットワークから参加するには、WebSocket対応のホスティングなどが必要です。

## 操作と目標

ゲームはタイトル画面から始まります。「はじめる」で旅支度（名前・部屋のコード・キャラクター）を整えて「この谷へ出発する」を押すと谷に入り、最初の1回だけ操作と最初の目標をまとめた「旅のはじめに」が表示されます（「次回から表示しない」で省略可）。同じタブで再読み込みした場合は「つづきから」で保存した持ち物のまま戻れます。招待リンクの `?room=` は旅支度に反映されます。ゲーム中は **ESC**（コントローラーは OPTIONS）でメニューを開き、もちもの・世界地図・探索手帳・三つの国・部族と招待・あそびかた・設定（環境音・全画面・視点）・タイトルへ戻る、を選べます。M / I / J で地図・もちもの・手帳を直接開き、H であそびかたを見直せます。自動テスト用に `?autostart=1` を付けると保存済みプロフィールで画面を省略して参加します。

画面は3Dワールドが全面で、左上にキャラクターの状態（名前・部屋・人数・日数・元気）、その下に目標、右上にメニューとミニマップ、右下に操作の案内、中央下にアクション、左下にチャットが浮かびます。新しい場所に入ると地名が中央に表示されます。

ローカル版はPS4コントローラー（DUALSHOCK 4）に対応しています。USBかBluetoothで端末につなぎ、ゲーム画面でボタンを一度押してください。**左スティックは浅く倒すと歩行、深く倒すと走行**。2回倒しや押し込みは不要です。右スティックでカメラ、×で採集・決定、□／R2で攻撃、△で船・マンモスの乗り降り、○で中止、OPTIONSでメニュー。詳しい割り当てと接続条件は[コントローラー操作](assets/gamepad-controls.md)とゲーム内の「遊びかた」にあります。

右上の地図から世界全図と現在地の周辺を切り替えられます。陸地または野営地を選んで「走って向かう」と、障害物を避けて移動します。海の向こうは13か所の野営地を選び「野営地へ遠征」で移動を省略できます。持ち物は保持され、騎乗中は降りてから遠征します。WASDで自分の操作に切り替えられます。14か所の焚き火で生肉を焼けます。

世界は東西4,096 m・南北2,048 mの有限範囲です。地図と歩ける陸地は同じ海岸線を使います。NOAAの地形と海面 −68.3 mから作った近似で、氷床・気候帯も簡略化しています。人物や建物の大きさは従来どおりです。[基準時代・資料・再現方法と限界](assets/geography/README.md)を参照してください。

木や岩などの基本モデルとテクスチャを共有し、雪・霜・灰・砂漠の材質で地域差を表現しています。雪の厚みを追加する方式ではなく、元の形に沿った表面処理です。制作と検証の記録は [地域素材のQA](assets/biome-game-qa.json)、比較画面は [地域表面レビュー](http://localhost:3000/biome-review.html) にあります。

仲間と木材12・石6を焚き火に届け、最初の野営地を完成させましょう。石斧があると木材・石の採集量が増えます。資源は一定時間で回復します。

マンモスは北西・南西の開けた草原を歩き回ります。近づいて槍を4回当てると倒せます。倒れる動作の後に肉へ変わるので、近づいて E または肉のクリックで生肉を1個ずつ採りましょう。1頭分の生肉4個を部屋の仲間で共有します。生肉はそのままでは食べられません。最寄りの焚き火の近くで E または「焼く」を押して3秒待ち、焼き肉を食べると元気が回復します。調理中に「中止」を押すか火から離れると、生肉を失わずに中止できます。

クロマニョン人とネアンデルタール人は、それぞれ女性・男性を選べます。初期選択は女性で、性別を未設定の既存プロフィールにも適用します。明示的に選んだ男性は再読み込み後も保持します。人間の集団・性別で能力は変わりません。猫耳のクノイチとこぐまを加えて、選べるモデルは6種類です。こぐまは独自のくま風キャラクターで、身長0.78 mに合わせた歩行・走行・カメラを使います。

刀は0.6秒の斬撃で、開始267 ms後に命中を判定し、700 ms間隔で使えます。魔法は400 msの詠唱後に光弾を放ち、7 m/sで最大8 m飛び、1.1秒間隔で使えます。いずれも1発25ダメージです。サーバーが命中と遮蔽物を判定し、他のプレイヤーや交易NPCには当たりません。

ネアンデルタール人のNPC「オル」は、木材または石2つをベリー3つと交換してくれます。NPCは5人の定員に含まれません。世界の暮らしや地形はゲーム用のフィクションです。

## カラス人間「白羽の呪術師」

白い冠羽、黒い羽毛、獣皮の服と杖を持つ敵です。北側 `(45, 16)` の開けた場所を巡回し、近づくと追いかけて杖で攻撃します。HP75で、槍3発の命中で倒せます。倒れる動作の後に消え、45秒後に再出現します。キャンプ周辺は安全地帯です。

杖に当たると元気が15減ります。元気が0になると4秒後に焚き火のそばで元気50に回復し、持ち物は保持します。復帰直後は5秒間保護されます。制作・組み込みの最新状態は [カラス人間の制作記録](assets/crow-shaman-request.json)、通信検証は [5人接続の記録](assets/crow-network-qa.json) に分けて保存します。

## 描画と地形の読み込み

地形は32 mの区画に分け、半径128 mの周囲だけ読み込みます。8,192区画の矩形範囲のうち陸地のある区画を読み込み、今回の実画面では最大68区画が常駐しました。地形のインスタンス描画と距離LOD、使わなくなった地域の12秒後の解放、遠方の人物・岩・建物・動作更新の省略を使います。地域の読込は同時2件まで、区画の追加は1フレーム2件または3 msまでに制限します。海岸線と気候のテクスチャは世界共通です。

地形・氷壁・火山は以前にTRELLISで制作したモデルを共用しています。今回の新規GLBは0、採用済み31モデルはすべて保持しました。火山の粗いLODは外観が崩れたため採用せず、13,382三角形の版を共用しています。雪・火山灰・砂塵は固定数の粒子をGPUで動かします。

描画上限は60 FPSです。今回の観測はシーン・同時に動くゲーム画面・読み込み状態で変動し、氷の海岸で58 FPS、検証タブを閉じた後の通常ワールドの地図で52 FPSでした。複数画面での低下も含む[実測値と条件](assets/paleo-world-game-qa.json)を記録しています。常時60 FPSや物理スマートフォンでの性能は保証していません。

## 現在の範囲

Three.jsで起伏のある地形、森林、川と橋、テント、焚き火、歩行する人物とマンモスを描画します。キャラクターの身長に近い高さから見る肩越しカメラが追従し、カメラが木やテントに入る際は距離を縮めます。Three.jsはnpmで導入し、`npm start` / `npm run dev` 時にブラウザ用モジュールを `public/vendor` にコピーします。外部CDNへの接続は3D描画に不要です。

人物・動物だけでなく、植物・岩・地形・テント・橋・道具・装備など、**全3DモデルをTRELLIS-2のimage-to-3D方式で制作**します。当初のClaudeによる制作から、2026-09-06のユーザー指示でCodexへ担当を引き継ぎました。生き物のリギング・スキンウェイト・アニメーション、静物の構造・原点・必要な可動部まで含めます。隣の `../threed-model-creation` の方式を採用し、詳細を [全3Dモデルの制作方針](ASSET_WORKFLOW.md)、作業ルールを [AGENTS.md](AGENTS.md) に記載しています。

歩行・走行は別のクリップを実際の移動速度に合わせて再生します。進行方向と最後の停止方向を保ち、アニメーションがワールド上の向きを上書きしない構造です。

当たり判定はサーバーで確定します。小屋、岩、木の幹、薪、乾燥棚、焚き火、橋の欄干、人、NPC、マンモスに対応し、走行時も細分化して判定します。クリック移動は静物と現在の人・動物・敵を避ける経路を探し、仲間に進路を塞がれた場合も再探索します。描画は60FPSを上限にし、非表示時の描画と遠方の敵の動作更新を省きます。マンモスの位置と動作も部屋の全員で共有します。

初期のコード生成モデルと旧2D描画を削除しました。モデルの読み込みや検証に失敗した場合はエラーを表示して描画を止め、旧モデルや別のモデルへフォールバックしません。

小屋は外形全体を障害物として扱うため、現在は屋内には入れません。当たり判定は軽量な水平面上の形状と地表の高さを組み合わせています。マンモスへの近接槍攻撃と倒れるアニメーションを実装しています。自由な転倒物理、押し合い、ジャンプ、槍投げ、対人戦は未実装です。

ゲームの進行はサーバーのメモリ内だけに保存されます。通信切断・同じタブの再読み込みでは、2分以内に接続が戻れば同じプレイヤーの持ち物・位置・元気・石斧・採集進行を復元します。騎乗と調理は切断時に解除し、生肉は残します。最後のプレイヤーが切断した部屋も復帰待ちの間は保持します。プロフィール画面で明示的に参加し直すと個人の進行はリセットされます。復帰待ちの期限が切れた空室は削除し、サーバー再起動時には全ての進行が消えます。

アカウントやWebSocket接続の認証は未実装です。現在は身近な仲間と動作を試すためのプロトタイプです。

既存クロマニョン人を保持し、残り15素材をCodexが画像から制作してゲームへ組み込みました。今回の参照画像はbuilt-in imagegen、3D復元はローカルTRELLIS-2です。Claudeは使用していません。人物2種、オル、マンモス、木、草、茂み、岩、薪、テント、乾燥棚、焚き火、槍、石斧、地面、川面、橋を検証済みGLBで表示します。

現在の構成は全31モデルです。人物6種類は各22本の骨と9動作、マンモスは24本の骨と5動作、白羽の呪術師は23本の骨と6動作を持ちます。槍・刀・石斧は手の骨格に接続します。クノイチは約7.34 MB、こぐまは約7.71 MB、刀は約2.02 MBで、元の形状を測定しながら軽量化しました。刀は必要なときだけ読み込み、同じキャラクター同士は形状とテクスチャを共有します。魔法は再利用する1つの粒子バッファで描画します。植物には遠景LODを使い、接地高さは復元モデルから測定しています。空、水流、炎、魔法の光、操作マーカーは実行時の効果です。

新しい素材構成で5人接続を確認しました。接続数、描画計測、実際に確認した操作と制約は [ゲーム検証記録](assets/open-world-game-qa.json)、素材別の状態は [制作記録](assets/README.md) を参照してください。[モデルレビュー](http://localhost:3000/model-review.html)で各素材と動作も確認できます。

画像から復元した試作素材のため、近接時の髪・毛皮・葉のまとまりや、小さな服の変形は残ります。皮のテントは両端の開いたシェルターです。地面と川面は同じ復元パーツを繰り返し配置します。

次の開発候補は、サーバー再起動にも対応する進行の永続保存、認証と公開環境の整備、建築や狩猟の発展です。

## 対象に依存しない槍攻撃（2026-09-06）

Fは対象の選択・存在・距離に関係なく攻撃動作を開始します。850 msの攻撃間隔を守り、333 ms後に人物の前方±55度、槍の射程、遮蔽物をサーバーで調べ、条件を満たす近い相手1体に25ダメージを与えます。遠い相手や背後の相手へ自動で向き直りません。近くの相手をクリックした場合は、その方向を向いて攻撃します。調理中のFは生肉を残して調理を中止し、攻撃へ移ります。

`shared/combat.mjs` が動物と敵の共通処理です。敵はサーバーの `room.enemies` に登録した `hostile: true` の個体が対象で、通常の仲間や交易NPCは対象外です。この変更では新しい敵の種類や出現地点は追加していません。自動テストは58件通過。[F攻撃の実操作・サーバー更新記録](assets/free-attack-qa.json)を参照してください。以前の48件の狩猟QAは当時の記録として保持します。
