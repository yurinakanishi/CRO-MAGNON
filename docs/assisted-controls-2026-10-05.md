# 自動視点と手操作の試作（2026-10-05）

通常メニューの「設定 → 操作 → かんたん・視点自動」で、W/S・左スティック上下を前後、A/D・左スティック左右を旋回として使う。停止中の左右はその場で旋回。設定はこのブラウザーに保存し、初期値は通常操作。「カメラで遊ぶ」の手操作は常に自動視点を使う。

同日の追加指定で、初心者モードと手操作中は手動の視点操作を全廃。ドラッグ・右スティック・ホイール・ズーム・視点戻し・仲間を見る視点を無効にし、設定と操作案内も自動視点に合わせた。通常操作では従来の視点操作を利用できる。「カメラで遊ぶ」は「手であそぶ」へ変更し、準備とコンパクトなプレイ表示を分けた。詳細は[初心者UIの変更](beginner-ui-2026-10-05.md)。

## カメラと移動

- `AssistedNavigation`が操作用の向きを保持し、アクションや速度ベクトルから逆算しない。前進・後退・旋回は独立。左右最大1.65 rad/s。
- 背後から初期距離6.5m以上、俯角0.32 radで追う。旋回はフレーム時間に基づく指数補間。右手・右スティックによる通常の見回しは不要。「見る」の拡大中は既存の回転を使用できる。
- 後退でも正面を保つ。既存の任意`move.facing`を移動中にも適用し、サーバーと予測処理で共用。通常操作は従来の移動方向を使う。
- 歩行面の高さを視点の基準とし、ジャンプの上下変位を追わない。地形の上下は緩やかに追う。
- 静物・城・洞窟の既存カメラ衝突判定を使用。壁では即座に距離を縮め、開けたときは時定数約0.42秒で距離を戻す。
- 攻撃・撫でる動作で人物が横を向いても操作用の向きを保持。意図的な旋回でも撫でを中断でき、所属は保持する。

## 手操作

| 入力                       | 動作                                 |
| -------------------------- | ------------------------------------ |
| 左手を基準より前へ押す     | 前進                                 |
| 左手を基準へ戻す／下ろす   | 停止                                 |
| 左手を基準より引く         | 後退                                 |
| 左手を左右へ動かす         | 左右に旋回                           |
| 胸の前で右手を銃の形にする | 1回攻撃。指を開いてから再入力        |
| 開いた右手を上げる         | 1回ジャンプ。下げるまで連発しない    |
| 低い位置で右手を横へ振る   | 選択された相手を撫でる／調べる／採集 |

左右の役割は既存の設定で交換可能。前後は指先を含めず、画像上の手のひら幅と手首〜中指付け根の長さの倍率の幾何平均を使う。前進開始12%・停止6%、後退開始18%・停止14%、確定90ms。旋回は手の位置から求め、画像中心を基準に倍率を補正する。停止位置で求めた幅Sに対し開始0.55S・停止0.35S・最大1.3Sとし、自然な押し引きの左右ずれを旋回にしない。相対zは形・向きの検査だけに使用。

画面端から移動手が外れた場合は、直前に確定した前後・旋回を継続する。画像内で有効だった手のひら5点のいずれかが端の6%以内にあり、その後に掌が欠ける／未検出になる場合だけ保持へ入る。枠外の推定座標で新しい操作量を作らず、認識済みの入力を保つ。両手が映らなくても、新しいカメラ結果が届く間は継続する。戻ってきた有効な掌で操作量を更新し、65msの補間でつなぐ。停止位置へ戻す／画面内で手を下ろす場合は即停止する。アクションの繰り返しは保持しない。UIは「画面外 · 直前の動きを継続」と表示する。

画面中央での喪失、大きな向きの変化、寸法の不整合は前後・旋回をゼロにする。結果が230ms以上古い場合も枠外保持を破棄して停止する。通常の喪失からは、新しい位置と寸法が120ms以上連続して整合することを確認して再開する。画面離脱・メニュー等の一時停止後は両手の停止位置を確認する。勝手な基準の取り直しはせず、座り直しには既存の再調整ボタンを使う。停止時は残りの補間を捨てる。枠外保持からの復帰では復帰待ちに戻さず、同じ動作が一度途切れるのを避ける。

初期調整は「両手の認識300ms → 楽な位置へ戻すための1秒 → 停止位置で1.4秒安定 → 250msの中立確認」。準備中はアクションを出さず、右手は低い位置で確認してからジャンプを受け付ける。

銃の形は独自判定で、親指・人差し指を伸ばし、薬指・小指を曲げる。中指は伸ばしても曲げてもよい。胸の前で140ms確定し、開いた指を120ms確認するまで再発動しない。不明・枠外の指は解除とみなさない。低い横振りに厳密な下向きの手のひらは要求しない。

## 対象補助

画面内、操作上の前方約±70度、遮蔽物なし、到達可能な高さを満たす候補を選ぶ。攻撃は現在の武器の射程内にいる生存中の敵だけを補助し、回避中を除外。サーバーも従来どおり距離・遮蔽物・攻撃条件を再判定する。

対象に「攻撃」「撫でる」「採集」の印を表示し、対象名と実際の操作を同じ選択へ接続。現在の候補が有効なら維持し、十分に優先度の高い別候補が450ms続いた場合に切り替える。無効な候補は直ちに除外する。botの一括撫では従来の群れ全体が対象。地域固有の調べる操作は既存の対象名表示を使い、前方・可視性条件を追加する。

## 確認範囲

初回試作はTypeScriptビルドだけを確認。その後ユーザーから提供動画での検証依頼を受け、実映像557フレームの比較、実ゲームでの録画入力、関連85テストを実施し、旧操作の単体テストを現在の仕様へ更新した。[動画検証の条件・結果・限界](hand-video-2026-10-05.md)。旧ブラウザーQAスクリプトには旧操作の期待値が残るため、今回は専用の動画QAを使う。初心者の理解、疲労、ライブカメラでの操作感、他の体格や撮影条件は未確認。

最初の実操作確認は「524へ近づく → 止まる → 撫でる → 後退 → その場で旋回 → 離れる」。まずキーボード／パッド、次に左手、最後に右手の順で確認する。比較用の「上下で前後」は今回追加していない。

既存GLB・画像・骨・アニメーション・保存形式・非表示設定を保持。手動サーバー再起動、保存の手編集・巻き戻し、公開・展示配布、commit/pushは実施しない。通常ローカルビルドのみ。
