# 人物カードのXアイコン（2026-10-16）

ユーザーの追加指定により、タイトルの「関わってくれた人たち」と洞窟の「壁画の人々」で、Xプロフィールへリンクするカードの右端にXアイコンを表示する。以前の「Xのマークは出さない」という表示指定を置き換える。

共通の `personCard()` で、検証済みの `https://x.com/<handle>` へリンクする場合だけ18pxのインラインSVGを追加した。名前とアイコンを含むカード全体が同じリンクになり、既存の新しいタブ・`noopener noreferrer`・リンクの読み上げラベルを保持する。SVGは装飾として読み上げとフォーカスの対象から外す。プロフィール写真や追加の画像通信は使わない。

タイトルは17枚中16枚、洞窟は16枚中15枚にXアイコンを表示する。XプロフィールのないOpenAI Dotsと、リンクを無効にする既存設定では表示しない。名前・名簿の並び・yuriを制作欄だけに載せる指定は保持する。

関連44テストが合格。実Chrome 155.0.8059.41のPC 1440×900とタッチあり390×844で、タイトル・洞窟の全カードの名前、リンク、アイコン数、18pxの寸法、カード内への収まり、スクロールを確認した。画像と結果は `output/playwright/contributor-x-20261016-01/`。ブラウザーエラー・ゲームAPI・WebSocket通信は0件。独立したブラウザー保存と一時ポートを使い、通常サーバーを再起動していない。実スマホ・Safari・物理パッドは未検証。
