# 仲間を近くで見る

りもねこ、524、9種類のbotを、世界の中で拡大して回り込んで見られるようにした。表示を再開したmaeにも同じ仕組みを適用する。元のモデル、骨、動作、素材、仲間の所属と進行は変更しない。

近くの画面内にいる仲間へ「りもねこを見る」などの短い行動を出す。クリック、X、コントローラーのR / R1 / RBで開始する。モデルへマウスポインターを合わせて上へホイールしても、その仲間を直接選べる。対象は8m以内、画面内、壁に隔てられていない仲間に限る。

開始時に正面へ回り、体格と画面の縦横比から距離を決める。ドラッグ／右スティックで回転し、ホイール／＋・−／L・Rで距離を調整する。拡大中は通常の自分のモデルだけを一時的に隠し、仲間を覆わない。通常視点へ戻すと復帰する。

移動、Esc、X、右スティック押込、ZL/L2で通常視点に戻る。メニュー、チャット、画面の非表示、コントローラー切断、ワープ、被弾、人物変更、ダウン等でも解除する。見る操作だけでは撫でや攻撃を送信せず、拡大中の単純なキャンバスクリックでも攻撃しない。他の参加者の視点には影響しない。

案内は既存のプレイ中の入力図へ統合し、最大3つの短い行動のみ。コントローラー図では肩のボタン・右スティック押込・キャンセル位置を点灯する。操作説明の画面やメニューは追加しない。通常カメラの衝突・地面・水面の回避を継続する。
