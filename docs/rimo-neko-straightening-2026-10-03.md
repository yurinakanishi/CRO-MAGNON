# りもねこの首と尻尾の向きを修正

ユーザー指定で、選択済みのC2表面01の顔が常に右を向き、尻尾も右へ曲がっていた状態を修正した。C2 / rig03をローカルゲームへ採用。以前の「元の頭の向き・尾を保持する」という記録より、今回の形状修正の指定を優先する。

## 形と動き

- 両目を結ぶ線から測った顔の横向きは32.3144度からほぼ0度へ。目の中央も胴体の中心へ揃えた。顔の12,528頂点は一体で回転・移動し、目の間隔や顔自体の形を保持した。首から肩へは滑らかにつなぐ。
- 尻尾の左右への偏りを、5本の骨と元の毛の表面で補正。上向きのカール、毛の質感、上下・前後の形は残した。待機中の小さな揺れも左右の中心を基準にした。
- 元の三角形の接続・UV・スキンウェイト・埋込画像を保持。形状を直すため頂点位置と骨の初期姿勢は意図的に変更している。Blenderの再書出しで頂点番号は変わるため、保持検査はUVごとの頂点・三角形・ウェイトの対応で照合した。
- 4,707個の足裏頂点は固定。29骨とIdle / Walk / Run / Pet / Happy / Hit / Hissの7動作を継続。喜びの首かしげなど、動作による一時的な傾きは残す。

配信は `public/models/rimo-neko/model-c02-r03.glb`。140,226三角形、191,975頂点、26,079,184 bytes。SHA-256は `2b303eb5967bcc5bb0fc1cc13c922ddc959fd08ddfc736366c6e05392fd2063f`。
遠景は `lod-c02-r03.glb`、22,436三角形、1,973,860 bytes、SHA-256 `ae8227092e0556b0642b1baae840cea8dae144a446b24087347a955d8b309495`。同じ骨・材質・クリップを共用する。

## 検証

- 書き出した実GLBの両目を表面の三角形から再測定。顔の横向き−0.000024度、目の中央Xは約−0.000005mm。尻尾の5骨のXは最大0.000006mm。180待機姿勢の平均も中央にあり、固定した右寄りはない。
- 元の画像SHA `cdc1a858935806ec21acc29af297284c696e0e359b342c4bf9b351567c2ca2e3` は一致。修正済み静止形状からリグ版への検査では全頂点位置・UVの差0。これは修正前の曲がった位置を維持したという意味ではない。
- 主モデル・遠景それぞれ全頂点を240Hz、2,403姿勢ずつ検査。Root移動0。走行時の最低Yは主−0.588mm、遠景−0.593mmで既存の許容範囲。歩行接地中の最大移動2.05mm。
- 喜びを480Hz、769姿勢で確認。Pet→Happy、Happy→Idleの継ぎ目は最大0.000054mm。足の最大移動0.000184mm。
- 修正した静止形状の6方向、最終配信GLBの7動作×3方向×6時刻＝126画像を目視確認。
- 全860テスト、型・strict、450JS構文、依存境界を確認。人物側の頭頂への撫で到達検査も通過。公開用派生モデルの105GLB・15,430個の非画像bufferViewの保持検査も通過した。
- 実Chrome2画面と通信3人で撫で・ハート・追従・被弾・威嚇・橋・帰還・再参加、両LOD・通常カメラを確認。7動作、79描画フレーム、15画像、エラー0。落ち着いた位置での撫での最大接触差は女性0.000218mm、タコ人間0.091673mm。通常3000番の4配信SHAも一致。`assets/rimo-neko/qa/c2-r03-game.json` と `c2-r03-delivery.json` に記録した。

ゲーム確認は保存しない独立サーバーを使い、撫で・帰還は実際の操作、位置・被弾・橋は明示した確認用状態を使った。背景タブの描画抑制で初回接近には補間遅れがあり、落ち着いた位置での撫でと別に記録する。持続FPS・実端末・小画面・長時間・全自己交差は今回検証していない。

15枚の保存PNGのうち、人物が猫を遮った正面1枚は撮り直した。通常カメラ1枚は描画コールバック外で消去されたcanvasバッファを保存したため黒く、画像証拠としては除外。通常カメラは再参加後の実Chrome画面をCUAスクリーンショットで直接確認した。これらの不適切なキャプチャも削除せず記録に残す。

## 制作履歴と保存

準備形状revision01は旧ウェイトによる局所的な引き伸ばし、revision02は尻尾の区間切替による不連続があったため不採用。連続した補正場を使ったrevision03を採用した。形状補正の辺長比は0.256〜2.501であり、首周辺を含むすべての距離が不変という主張はしない。

数値検査の初回には浮動小数点の扱い、再書出し後の頂点順、ランドマークの最近傍点近似による検査側の失敗があった。最終版では実表面の三角形内の座標から測る。LODの先行実行による入力不足も完了後に再実行した。失敗ログと全試作を保持している。

制作元は `assets/rimo-neko/workflow/straighten-candidate-2.py`、形状検査は `scripts/qa-rimo-c2-straightening.mjs`。原画像、旧rig02、修正試作01〜03、採用rig03、Blender、QAを保持。新しい正本保管先はモデルライブラリの `models/rimo-neko/candidate-2/game-straightening-20261003`、受領記録は `assets/rimo-neko/archive-straightening-20261003.json`。

通常3000番の既存dev配信を継続し、サーバーの独自再起動・保存編集・保存巻戻しは行っていない。公開デプロイ・展示配布・commit/pushも行っていない。全素材の原画像履歴監査は、以前からのneanderthal-hunterの原画像欠損があるため今回は再実行していない。
