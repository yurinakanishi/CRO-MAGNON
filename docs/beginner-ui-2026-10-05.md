# 初心者向けの完全自動視点と手操作UI（2026-10-05）

ユーザーの「配信」は「廃止」の意味と確認済み。初心者モードでは手動の視点操作をなくし、手操作画面の情報量を減らす指定。公開版への配信依頼ではない。

## 変更

- キーボード／パッドの「かんたん・視点自動」と手操作中は、マウス・タッチのドラッグ、右スティック、ホイール、ズーム、視点戻し、仲間を見る視点への変更を受け付けない。自動追従・壁への接近・後退時の向きを維持。操作用のクリックは通常の初心者モードで維持する。
- 視点の設定は「自動」のみを表示。パッドの見渡す表示と視点操作の候補を省き、通常へ戻すと手動操作と設定を復帰する。メニューのhidden属性が既存flex指定に上書きされないよう修正。
- 入口を「手であそぶ」へ変更。準備は「手を見せる」「楽な位置で止める」の2段階と、その時点ですること1つ。カメラ映像は準備／調整の際に表示する。
- 準備完了後は318px幅の表示へ自動で縮小。現在の動き、止め方、右手の3動作の図、近くに対象がいるときの案内を表示する。各指・寸法・21関節・性能数値は閉じた詳細へ移す。
- 「動かし方・調整」では移動とアクションの図を切り替えられる。開いている間は停止し、「ゲームへ戻る」後に中立を確認して再開。枠外継続もこの停止時に破棄する。
- 枠外へ出た場合の直前入力の継続を保持。手が戻ったときに通常の補間でつなぐ。UIは「手が画面外です・動きは続いています」と、画面内へ戻す止め方を示す。

## 確認

関連101テスト、TypeScript通常／Cloudflare／strictビルド、依存境界と差分の空白確認が成功。

保存なしの独立サーバーとChromeで、通常設定から自動へ変更したときの視点ボタン非表示、および通常へ戻した後のズーム復帰を確認。提供動画を使った実ゲームでは、マウス／ホイール／キー／合成パッド入力で自動視点が変わらないこと、準備から小さな表示への自動切替、説明中の停止・終了後の中立復帰、詳細が初期状態で見えないことを確認した。1280×800、390×844、844×390で配置を検査。

証拠は `output/playwright/beginner-ui-20261005/`。`settings/` が通常メニュー、`game/` が初回の手操作と動画検証、`final/` が最後の表示修正後。サイズ変更直後の初回縦画面画像は描画待ちが足りなかったため、最終検査では4回の描画完了を待って撮影した。

最終動画検査はCPU認識538回、ゲーム状態720観測、枠外継続30観測。攻撃／ジャンプ／撫での誤命令、ページ例外、外部通信は0。通常3000番の関連8ファイルはビルド結果とSHA-256が一致し、既存devで反映済み（`served.json`）。

実機のカメラ／物理パッド、初心者本人の理解・疲労、別の体格・照明、持続FPSは未検証。通常サーバーの保存・仲間・モデル・非表示設定を保持し、手動再起動・保存編集・原動画変更・外部送信・公開／展示配布・commit/pushは行わない。
