# 左手の提供動画による移動検証（2026-10-05）

ユーザーの `WIN_20261005_14_49_41_Pro.mp4`（1920×1080、37.137秒）をローカルで解析し、前進・後退・停止と斜めの操縦を修正した。最新の動画テスト依頼を、以前の「テスト不要」の指定より優先した。左右は現在の仕様どおり旋回であり、斜めは前後＋旋回の組合せ。

## 再現した問題と修正

以下は最初の検証時点の記録。「画面外では停止」の扱いは末尾の追加指定で変更した。現在の枠外継続の仕様は[自動視点・手操作](assisted-controls-2026-10-05.md)を参照。

- 4.5秒付近で手のひらが画像の端へ触れると停止し、その後も正確に元の位置へ戻すまで前進・後退できなかった。14秒台でも再発。検出喪失時は停止するが、新しい有効な手を120ms以上連続確認するとその位置から復帰する。両手の同時復帰は不要。メニュー／画面離脱後の中立確認は保持。
- 画像端の内側1%を一律に無効にしていた。移動用の手首・指の付け根5点は画像全域で受け付け、実際に枠外の点は引き続き使わない。指先だけが欠けても掌が見えていれば移動できる。
- 前へ押したときの自然な横ずれを旋回と判定していた。投影倍率の補正を維持しつつ、旋回の不感帯を拡大。
- 29秒付近の斜め後退では、掌の縦横倍率の少しの不一致で入力が途切れた。倍率の整合範囲を1.22から1.32へ変更。大きな向きの変化、指の伸縮だけ、片軸だけの大幅な拡大は拒否する。
- 終盤の停止位置が初期位置より少し奥になっていた。後退の開始／停止幅を18%／14%へ広げ、停止姿勢での微速後退を抑えた。
- 認識ごとの段差を描画時間に基づく65msの補間で滑らかにした。停止・喪失・230ms失効はゼロにし、惰性で歩かせない。
- 掌が水平になる右手アクションを潰さないよう、形の判定は相対3D寸法、前後の操作量は画像上の2寸法と分離。絶対距離としてMediaPipeのzを使わない。

## 実ゲームへの接続

通常保存を使わないループバックのメモリー上の部屋で、動画をCanvasのcaptureStreamへ流し、**実際のMotionCamera → CPU Worker → 入力処理 → 移動命令 → サーバー → 描画**を確認。準備だけ同じ2秒のフレームを保持し、その後は0.5秒から等速再生した。検査用フックは検証ブラウザーへの応答だけへ追加し、製品コードへ座標記録機能は加えていない。

1280×800・軽量画質の1回では496認識結果、実効約12.25Hz。認識時間の中央値65.6ms、95パーセンタイル94.5ms。取得から結果までの中央値66.7ms、結果から入力適用までの中央値0.1ms。描画時間の最後の600標本の中央値33.3ms。身体動作から画面表示までの遅延、長時間平均FPS、ライブカメラ性能の測定ではない。

前進・後退の直線区間は旋回ゼロ、人物の向き0・視点πを保持。12〜13秒台と18〜20秒台、34秒終盤の停止ではサーバー上の位置も不変。斜めで操作方向と自動カメラが追従し、画面外で停止して復帰後に後退を再開。移動だけの動画から攻撃・ジャンプ・撫での命令は発生しなかった。3回の等速ゲーム検証で各回ページ例外0、外部HTTP要求0。実時間の認識では22秒付近の手の重なりでも一時停止があり、動画を固定時刻で解析した比較表と完全には一致しない。

初回の動画丸ごとのブラウザー応答ではブラウザーが終了。範囲指定のローカルHTTP配信へ変更して完走した。Playwrightの録画用FFmpegはこの実行環境で起動拒否となり、ブラウザー内のMediaRecorderで確認動画を保存した。失敗記録は消していない。

確認動画：`output/playwright/left-hand-video-20261005/game-preview/game-review.webm`（960×600、5,083,672 bytes）。ゲームの実描画へ元映像の鏡像と入力値を重ねたもの。生成後にChromeで22秒へシークし、映像を復号して画面も確認した。録画中の性能は録画なしの値と分けて記録。

## 追加指定：手が画面端から消えた間の継続

ユーザーの「画面外へ出る直前の判定を続けてほしい」に従い、画像端付近で有効だった移動手が見えなくなる場合、最後に確定した前後・旋回を保持するよう変更した。旧記録の画面外での停止より、この指定を優先する。

手のひら5点のいずれかが画像端6%以内にあり、移動または旋回が有効だった場合だけ保持する。新しいカメラ結果が続く間は固定時間で解除せず、両手の未検出も許容する。枠外の推定座標から方向や速度を作り直さない。手が戻ったら新しい有効な掌で入力を置き換え、保持前の3標本の中央値を残さず、通常の65ms補間でつなぐ。同じ動作なら再取得待ちによる停止は入れない。

停止位置へ戻す、画面内で手を下ろす、閉じる・大きく傾ける、中央で見失う、カメラ結果が230ms以上更新されない、一時停止・終了・再調整では保持を解除する。左手を上へ動かすだけでは停止しない。見えていない手の攻撃・ジャンプ・撫でを反復しない。画面表示は枠外継続と再認識待ちを区別する。
