# 採取物への接近時の非表示を修正（2026-10-16）

ユーザー報告: ベリーや石が近づくと消え、採取対象が分からなくなる。木が視界を空ける挙動は維持する。

## 原因と変更

`src/world3d.ts` は採取用のベリーにも、カメラから人物への視線が茂みを通るとモデル全体を隠す処理を適用していた。実Chromeで、PCは対象から0.80 m、スマホ相当は0.48 mに接近したときに茂みと果実が消えることを再現した。採取の入力判定自体は残っていたが、見える対象がなくなる状態だった。

採取物の表示更新を `updateResourceVisibility()` にまとめ、視線による非表示を適用しないようにした。ベリー・石・薪・黒曜石は近づいても表示を保つ。残量0と従来の遠距離描画制限は維持する。景観用の木・茂みの視線処理は変更していない。モデル・配置・当たり判定・採取距離の変更はない。

採取用の石は今回の修正前のPC接近条件では消えなかった。別原因を推測して変更せず、修正後のPC／スマホ相当で表示・採取を確認し、回帰テストの対象に含めた。
