# 524を撫で終えるとdotsの仲間へ追加

後続の[期限なしの仲間状態](524-bond-2026-10-02.md)で、切断・保存復元による所属解除を撤去した。以下は初回実装時の記録。

524への接近・撫でる1100ms・喜ぶ1800msが完了すると、その人の10匹目として合流する。
C／L3で順番に投げられ、Q／十字↑で他のdotsと一緒に戻る。個別に持ち上げる操作は不要。
投げた場所では呼ぶまで待機し、持ち主の移動・ワープ・乗船・ダウンでは自動回収しない。

## 実装

- もともと部屋に1体だけいる524を共有する。各人へ配る基本9種類には含めず、撫で終えた人だけに条件付きで追加する。
- `squadPlayerId` と `squadMode` を524の公開状態へ追加。dots側には安定したID `orb:companion-524` の操作状態を1件だけ置き、位置・向き・被弾判定を元のNPCと同期する。
- 撫でる途中の中断では加入しない。再度の撫でや被弾の間は投擲候補から外す。別の人が最後まで撫でると同じ1体を引き継ぎ、中断・相手の切断では前の所属を保持する。
- 元の524レンダラーだけを使う。採用中の `model-midpoint-r01.glb`、30cmの体、20骨、`Floating_Ripple`、喜ぶ回転とハートを保持。
- 投擲中は動いている手の15cm上へ身体中心を合わせ、同じ位置から放物線を描く。飛行時の傾きと浮遊位置での短い着地反応を配置制御として重ねる。人物側の既存の投げる・呼ぶアニメーションを使う。
- 524の半径18cmを着地点・移動・衝突判定にも使用。手の中・飛行中・着地中・収納中は地面上での撫で／攻撃対象にしない。
- 加入後だけ通常メニューの種類選択を10個にする。所属が変わると開いているメニューも更新する。削除済みの右下dotsパネルとESC表示は追加しない。
- 「キャンプへ帰す」・持ち主の切断では仲間枠を外し、元の524が帰る。保存の読み込み時も従来どおり帰還し、再度撫でて加入できる。持ち物や進行の保存形式は変更しない。

GLBのSHA-256は `77faeb7e7b0a34cd1aa6e23b728cbaf295227998791bb437977a8ff2abfbb3b9` のまま。
