# 風・川を控えめにし、効果音を素材から作り直す

2026-10-06。追加回答「改善してゲーム内にも戻す」により、以前削除した17分類も復帰する。草・煙・波紋・洞窟の塵は維持する。

## 調査と設計

- [Greg Lester / Game Audio Learning Portal](https://www.gameaudiolearning.com/knowledgebase/how-to-record-foley-for-games)：動作の録音、素材の組合せ、地面別の足音、歩行アニメーションとの同期。常時鳴る音は低く、実際に行動が起きたときだけ鳴らす。
- [HaelDB / Cloth & Leather](https://opengameart.org/content/footsteps-leather-cloth-armor)：柔らかく短い布・革の素材（CC0を選択）。ジャンプ・乗降・撫でる動きへ。
- [Kenney Impact Sounds](https://kenney.nl/assets/impact-sounds)：CC0の草・接触・木等。草の足音、被弾、採集へ。
- [Corsica_S / 雪の足音](https://opengameart.org/content/42-snow-and-gravel-footsteps)、[rubberduck / 水音](https://opengameart.org/content/40-cc0-water-splash-slime-sfx)、[qubodup / 竹の振り音](https://opengameart.org/content/swish-bamboo-stick-weapon-swhoshes)：CC0。雪・水・攻撃・投擲をそれぞれの素材へ。
- [Zabuhailo / catHisses1](https://freesound.org/people/Zabuhailo/sounds/146963/)：猫の威嚇のCC0実録音。公開HQ MP3を使用（原96kHz WAVにはログインが必要）。
- 呼ぶ笛と成功／発見通知は既存のCC0 VSCO 2 CEの笛・ハープを使用。新たな電子ビープは足さない。

風は同じ野外録音の穏やかな部分を使い、900Hz以上の棚型EQ、1.6kHzの緩いカットと1.8kHzローパス、素材音量-38LUFS（前回-32）へ。ゲーム側の風量変動も狭める。川は-29LUFS（前回-25）、最大ゲイン0.34（前回0.42）へ。

試聴の「今回」は音量を持ち上げて揃えず、初期設定のゲインを焼き込む。風／川は直前の版との比較、効果音は削除前との比較を別々に表示する。直前版はassets/nature-audio/before-soften-20261006へ保存済み。

## 実装と検証

1. 原本・ライセンス証拠・SHAを保存し、44.1kHzの短いMP3へ加工。地面ごと複数素材、過剰な音程変更なし。
2. 効果音音量を独立設定。足音は実移動と接地・歩行周期へ同期。状態差分は初期接続／復帰／ワープで基準化し、過去イベントや一括同行の音を重ねない。
3. 短音の同時数・各イベントの間隔を制限。消音、非表示、切断、破棄で止める。
4. 型／関連テスト、全音源のデコード・ピーク・継ぎ目、保存なし実Chromeで操作・音量・復帰・全個別試聴を確認する。
5. 起動中8787の全ファイルSHAを確認し、今回のファイルのみ控えて反映。公開MMO・固定展示・ユーザー保存は変更しない。

## 完了した内容（2026-10-07）

- 復帰した17分類：草／砂／石／雪／水の足音、攻撃、ジャンプ、被弾、採集、松明切替、乗降、呼ぶ笛、投げる、撫でる、猫の威嚇、成功通知、発見。37短音の素材を制作し、合計51 MP3・6,550,373 bytes。48kHzデコード上限128,284,224 bytes（約122.4MiB）。
