# dotsと524の投擲中の1回転

全9種類のdotsと加入済み524が、900msの飛行中に前へ360度回転する。
離す瞬間と着地で回転速度を落とし、頂点付近で上下が反転する。
共有された投擲時刻から角度を計算するため、描画頻度・途中表示で回転回数が変わらない。
着地・帰還・追従では投擲の回転を残さず、集合後は持ち主と同じ方向に揃う。

地面中心のdotsは配信モデルの高さから身体中央を軸に補正し、足元を中心に振り回さない。
元のThrown_Loopの伸縮・揺れも飛行進捗に合わせて一度だけサンプルする。
身体中央の原点を持つ524は既存の姿勢グループで回す。Floating_Ripple、喜ぶ動作とハートを保持。
元GLB・骨・ウェイト・保存形式・弾道・判定・着地点は変更していない。

関連54テスト成功（今回の追加3件）。身体中心の固定、四方向での360度回転、頂点での反転、
描画頻度に依存しない途中表示、全10種類の着地・帰還での姿勢復帰を確認。
型／strictビルド、JS構文、依存境界、変更ファイルの書式も成功。
実Chrome2画面＋通信3人で、撫でによる524加入・10連投・待機・Q帰還を確認。
全10種類×2画面の20観測で各25〜30飛行フレーム、途中の逆さ姿勢、単調な1回転、着地での復帰を確認。
観測末尾の最小角度359.28度、計算上の終端360度。ブラウザーエラー0。
