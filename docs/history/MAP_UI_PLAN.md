# 地図とワープの操作を整理する

ユーザー指定：BotW／TotKの地図UIを参考に、地図を見やすく、地図から簡単にワープできるようにする。

参考：
- https://interfaceingame.com/screenshots/the-legend-of-zelda-breath-of-the-wild-map/
- https://stamen.com/cartographers-play-video-games-a-review-of-the-map-in-the-legend-of-zelda-tears-of-the-kingdom/

地図を主役にした全画面、静かな地形と明るい移動地点、選んだ地点名と決定操作を近接させる考え方を取り入れる。作品の画像や固有装飾はゲームへ転用しない。

実装：全画面の地図、固定の行き先カード、拡大縮小・ドラッグ移動・現在地への復帰、密集地点のまとめ表示と個別選択、読みやすい地点名、詳細表示の切替。既存30焚き火・明示的なワープ確定・サーバーの条件を保持する。

検証：投影とズーム・密集地点の単体検査、既存ワープ検査、ビルド・型・構文・依存境界、ブラウザーで世界／湾／現在地・ワープ・画面サイズと操作を確認する。

## 後続指定と実装結果

「余計なテキストはいらない。地図のタイトルもいらない」を反映。タイトル・導入文・操作説明・資料の長文を地図画面から撤去した。範囲の切替、ワープ／現在地の小さな凡例、地点名・距離・決定ボタンと名前の選択欄だけを残し、ワープ不可時だけ理由を表示する。

全画面化し、PCは右、縦長は下に行き先と決定を固定。地理は保持し、地図専用の落ち着いた色と海岸線へ変更（ミニマップの配色は保持）。緑の焚き火、金色の選択地点と現在地を分ける。地名の重なりを抑え、密集地点は件数付きでまとめて、選ぶと拡大と名前の候補を出す。全30地点は常に名前から選べる。地図のドラッグ、ホイール／＋−、1〜32倍、現在地に戻す操作、探索情報の切替を追加した。

地図からの選択後はワープボタンへフォーカスし、次のEnterまたはコントローラー決定で移動する。選択だけで移動せず、既存のサーバー検査・到着後の地図閉鎖・描画と予測のリセットを使う。接続状態も決定ボタンへ即時反映する。

## 確認

- 全454テスト通過後、最終の地図・ワープ・Gamepad・方向操作34テストを再確認（新規の地図3とGamepadフォーカス1を含む）。初回の新規GamepadテストはNode用DOMモックのHTMLSelectElement不足で失敗し、モック補完後34件すべて成功。
- strictを含むビルド、239 JS構文、依存境界を確認。
- 独立した保存なしの3031番と実ブラウザーで、通常の開始・再開、地図のマーカーから南アメリカへのEnterワープ、密集地点からはじまりの焚き火へ帰還、影の庭の条件、名前から湾へのワープと到着を確認。位置・元気・持ち物・時計の設定なし。
- 1440×900、390×844、844×390で目視確認し、タイトルなし・画面内のワープ操作・横方向のはみ出しなし。ドラッグ60×30pxで地図上の現在地が同じだけ移動し、ホイールで拡大、現在地操作で中心と1倍へ戻ることを観測。通常の検証中のブラウザーエラー0。
- 通常3000番の7ファイルの配信SHA一致を確認。サーバー再起動・保存の再適用は不要。記録は `output/playwright/map-ui/delivery.json`。
- 物理コントローラー、タッチ端末の実機、全地点での外観と長時間負荷は未検証。展示／PC2・公開デプロイは変更していない。

海岸の元データと時代設定の資料：
- https://www.ncei.noaa.gov/products/etopo-global-relief-model
- https://cp.copernicus.org/articles/12/1079/2016/

最終確認：確認用3031番のNodeプロセスを作成ファイルの時刻・PID・実行パスで照合して終了。地図を開いたまま通信が切れた時、ワープが無効になり「接続を待っています。」へ変わることも実ブラウザーで確認した。通常3000番は停止していない。検証タブを閉じ、画面サイズの上書きを解除した。

## 2026-09-10 地図UI/UXの再設計

- 右側を「行き先カード＋地域別の一覧」に変更。名前の選択欄（select）と「このあたりの焚き火」の別枠を廃止し、30地点を「はじまりの地・三つの岸の湾・各大陸・探索の地域」に分けて常に一覧に表示。各行に現在地からの距離（施錠中は「旅の証が必要」）を出し、選択中の行と密集地点を広げた行を強調する。
- カードは未選択（焚き火を選ぼう）・選択済み（地域名・名前・距離・ワープ）・不可（理由）の3状態。ワープボタンにEnterの印を表示し、選択後はボタンへフォーカスする従来の流れを維持。
- 地図の印を暖色の炎に統一し、選択地点は金色＋脈動リング、現在地は明るい矢印＋リング＋地名。凡例を地図の左下へ移し、地図の高さを広げた。
- 一覧から密集地点の中の名前を選ぶと、その地点を中心に3倍へ広げて印を分離する。密集の印を押すと2.5倍へ広げ、一覧の該当行へフォーカスする。
- 操作追加：地図のダブルクリックで拡大、地図をクリックして矢印キーで移動（地図はtabindex=-1で、コントローラーの項目には入らない）。
- 縦長ではカードを横並び（名前と決定）にし、一覧をその下に置く。範囲の切替は折り返さず横に流す。
- 確認：455テスト・型・構文・依存境界すべて通過。独立の3031番（保存先は一時フォルダー）で1440×900・390×844・844×390を目視。一覧から「長い谷の国」を選ぶと3倍で密集が開き、ワープの実行で到着とトーストを確認。通常3000番のサーバーは9:03起動の古い実行で、ワープに応答しなかったため確認には使っていない（停止もしていない）。
