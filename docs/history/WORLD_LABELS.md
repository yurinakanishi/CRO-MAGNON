# 頭上の文字と戦闘HPバー（2026-09-10）

ユーザー指定でマンモス・敵モンスターの名前、状態説明、乗り方や肉の採取案内を頭上から削除。木材・石・ベリー・黒曜石など、採集資源の名前ラベルも生成しない。

HPバーだけを残し、サーバーの状態で生存・HPが0より大きく最大値未満・自分から水平20m以内の場合に表示する。騎乗中のマンモスは非表示。離れたとき、死亡・肉・再出現待ち、全回復では非表示。誰がダメージを与えたかの限定や表示タイマーは追加しない。画面端の操作UI・対象カードと地名・住人・プレイヤー表示は今回の対象外。

変更は `src/world3d.ts`、`src/world-scenery.ts`、`src/style.css`。攻撃・採集・騎乗・保存のルールやGLBは変更しない。並行作業中の共有ドメイン等を一括反映せず、変更した2ブラウザーモジュールとCSSだけをdistへ出力。

検証：strictを含む型チェック、関連12テスト、依存境界、対象TS書式、変更JS構文を通過。独立したメモリー内サーバーと実Chromeで動物／敵の無傷・被傷・遠距離・死亡・再出現待ち・全回復の12状態と、採集資源57件のラベル生成0、頭上の文字0を確認。1440×900、390×844、844×390を記録しブラウザーエラー0。HP・位置・フェーズ・カメラはQA準備値で、実攻撃の新規通し検証ではない。初回の限定出力がCommonJSとなった問題をESM出力へ修正して再確認した。

再現と画像・結果：`output/playwright/world-labels/verify.mjs`、同フォルダーのPNGと`summary.json`。通常3000番は確認時に待受なし。通常サーバーの起動・再起動、保存への書込・再適用、展示／PC2更新、公開デプロイは行っていない。
