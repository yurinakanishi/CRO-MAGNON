# 力尽きたときに膝から崩れる動作

2026-09-09。対象は選択できる全7外見。力尽きた状態では現在の通常姿勢に代えて、膝が折れ、両膝をつき、腕と胸が地面へ落ちて静止する1.8秒の `Downed` を追加する。

- 採用中GLBの形状・材質・骨格・ウェイト・既存クリップを保持し、別revisionへ専用クリップだけを追加。既存のTRELLIS由来の肌を実際に曲げる。
- 各骨格と変形後の表面に合わせて接地を補正。手作業で設計した創作動作であり、実写から抽出した動作ではない。
- 既存のサーバー確定 `downedUntil` と致命傷の `hurtAt` を使用。4秒後の回復・持ち物・被弾判定・移動速度を維持する。回復待機が延びても巻き戻さない。
- 歩行・攻撃・ジャンプ・肩乗りなどを終了して優先再生し、終端姿勢を回復まで保持する。途中表示・遅延読み込みは経過時間へシークする。
- 最終GLBの構造・既存データ一致・60Hzの変形表面と関節、ブラウザーで複数方向の再生、実際の力尽きと回復への接続を確認する。確認範囲と未検証条件を結果へ残す。
- 通常サーバーの保存とプロセスを保持し、クライアントと素材を反映する。展示更新・公開デプロイは対象外。
