# 自動視点と手操作の開始

2026-10-05更新。[片手操作の仕様と確認範囲](../single-hand-controls-2026-10-05.md)。

## 先にキー／パッドで試す

ゲーム内のメニューから「設定 → 操作 → かんたん・視点自動」を選ぶ。W/Sまたは左スティック上下で前後、A/Dまたは左右で旋回する。視点は完全に自動。ドラッグ・右スティック・ホイール・ズーム・視点戻し・仲間を見る視点への切替は無効になり、案内や設定からも省く。停止中も左右だけでその場で向きを変えられる。「通常」で従来の操作へ戻る。選択はブラウザーごとに保存される。

最初の確認コースは「524へ近づく → 停止 → 撫でる → 後退 → 旋回 → 離れる」。

## 手で遊ぶ

1. ゲーム参加後に「手であそぶ」を押し、ブラウザーでカメラを許可する。
2. 好きな片手のひらを見せる。右手・左手は自動判別するので、選択は不要。続いて肘を上げすぎず、楽な位置へ戻して少し止める。反対の手・顔・肩は不要。
3. この位置が停止位置として登録される。準備中の手上げではジャンプしない。準備が済むと、自動で小さな操作表示になる。
4. 認識された手を前へ押して前進、元の位置へ戻して停止、基準より引いて後退する。左右へ動かすと旋回。手を下ろしても停止する。
5. 同じ手を胸の前で銃の形にすると攻撃。親指と人差し指を伸ばし、薬指・小指を曲げる。中指はどちらでもよい。指を開いてから次を出す。
6. 押し引きせずに開いた手を上げると1回ジャンプ。低い位置で横へ振ると、選ばれている相手を撫でる・採集・調べる。アクション中は移動を止め、元の位置へ手を戻すと移動できる。
7. 移動中に手が画面端から外れると、直前の移動・旋回を継続する。手を画面内の停止位置へ戻すか、画面内で下ろすと止まる。画面中央での認識抜けやカメラの更新停止では止まり、同じ手の再認識を確認して再開する。メニューや画面離脱後も同じ手を停止位置へ戻して再開する。
8. 「動かし方・調整」を開くと停止し、手の動かし方を図で確認できる。「ゲームへ戻る」を押し、同じ手を停止位置へ戻すと再開する。座り直す／使う手を替えるときは「カメラ・手の位置を調整 → 手の位置を合わせ直す」を押し、使いたい手を見せる。左右の選択は不要。終了は「やめる」。タイトル復帰・ページ離脱でもカメラを解放する。

手操作中の視点は自動。後退で反転せず、撫でる・攻撃の向きやジャンプの上下には大きく追従しない。前方の届く相手を補助選択し、印と名前で示す。開始後に反対の手が映っても勝手には切り替えない。以前の手の選択欄は撤去し、保存されていた左右の設定も使用しない。

## 認識表示

プレイ中は現在の動き、止め方、同じ手で行う3動作と、近くの対象だけを表示する。映像・各指の状態・寸法・処理時間は常時表示しない。「動かし方・調整 → カメラ・手の位置を調整 → 詳しい設定・認識の確認」で必要なときだけ開く。

「手の大きさ100%」は登録時の手のひらの寸法。指先までの倍率も参考表示するが、前後入力には使わない。画像上の倍率であり、PCからの実距離ではない。提供された1本の動画で前後・停止・旋回を調整した。[検証結果](../hand-video-2026-10-05.md)。前進開始12%・停止6%、後退開始18%・停止14%。撮影条件や姿勢が変わったら停止位置を合わせ直す。

関節のガイドは初期状態では非表示。詳細で「手の関節を表示」を選べる。骨格は現在の推定位置を表し、点ごとの信頼度ではない。古い結果は消す。CPU Worker・15Hzが初期値。映像・骨格は外部へ送信・録画・保存しない。

実機カメラ／仮想カメラの選択、CPU/GPU・認識10/15/20Hz・映像のみを既存設定から変更できる。すでに起動中のサーバーや保存を初期化しない。

モデルは同梱し、ゲーム起動中に外部から取得しない。旧Poseモデルは履歴として残るが現在のWorkerは読まない。

展示CSPにはwasm-unsafe-evalだけを追加。JavaScriptのunsafe-eval、COOP/COEP、外部認識APIは追加しない。
既存motion-r01 ZIPには今回の手専用モデルへの変更は含まれない。

## ブラウザーと展示LAN

カメラはsecure contextが必要。各PCのlocalhost/127.0.0.1から開き、ゲーム通信だけをLANホストへ接続する。
他PCのhttp://10.10.10.xを直接開くと使用できない場合がある。セキュリティ設定を無効化して回避しない。
HTTPSのiframe埋め込みではカメラ許可も必要。
WASM SIMD、module Worker、OffscreenCanvas対応のChrome/Edgeを想定。
起動失敗は理由を表示して解放する。GPU失敗時は終了してCPUを選択。Safari/スマートフォン実機は未検証。

## 集計

開発用のresetMotionMetrics()/motionDiagnostics()は状態・設定・時間分布だけを扱う。
集計はメモリ内。保存する場合も数値だけにし、カメラ映像や個人の骨格を記録しない。
取得→結果→適用の時間は、身体動作→画面表示の遅延とは異なる。
