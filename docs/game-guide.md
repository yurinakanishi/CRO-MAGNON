# CRO-MAGNON ゲームガイド

ゲーム内の探索手帳を廃止したため、掲載していた地域の説明・物語・目的・報酬をこの文書に保存する。ローカル検証・展示・MMOは同じ地域定義を使う。

## 旅と操作

難易度は「普通」の値に固定し、開始時にも設定メニューにも選択項目を置かない。以前の「簡単」「難しい」の設定や保存データから再開しても普通になる。展示専用の体力・攻撃倍率などは既存の展示ルールを使う。

はじまりの谷から自分で歩いて探索する。地図はミニマップから、持ち物・仲間の選択・設定はメニューから開く。クラフトは持ち物画面の「つくる」にまとめ、別タブには分けない。スマホは縦持ちで移動パッドと行動ボタンを使い、視点は自動追従とスワイプで調整する。会話は吹き出しアイコンから開き、メッセージを送れる。詳しいキー・パッド操作は[README](../README.md)を参照。

石・木材・ベリーは現地で採集する。持ち物画面で石斧（木材3・石2）、丸木舟（木材12）、黒曜石の刃（黒曜石2・打ち石に石1、石は消費しない）、黒曜石の槍（刃1・木材1）を作れる。槍は木槍を使う人物用で、強化後も装備品として持ち物に表示する。作成動作や待ち時間はなく、材料を消費してすぐ所持品へ追加し、ダイアログ・フォーカス・スクロール位置を保つ。所持数、所持材料／必要数、不足数、作成結果は同じ画面に表示する。舟は作成時には水面に出さず、海岸で出航し、岸に降りて回収できる。

焚き火の近くでは、持ち物の「つくる」から肉・魚・貝・火根・香草焼き根を即時調理できる。生肉などの持ち物カードから焼く場合も同じ。画面内の食事操作は引き続き体力を回復する。地上の焚き火から直接行う調理には従来の作業時間がある。材料不足・所持上限・騎乗中・行動中などは作成できず、理由を表示する。

仲間はメニューの「連れていく仲間」で選び、近くで撫でる・投げる・呼ぶなどの直接操作を使える。

アプデの洞窟では攻撃できず、手には松明だけを持つ。Lキー、メニュー、スマホの松明ボタンで火を消したり灯したりできる。消しても松明は手に残り、洞窟を出ると元の武器や石斧へ戻る。洞窟内では仲間を手に取って投げられないが、同行・撫でる・呼び戻しは使える。

## 探索の進め方

6地域を発見し、それぞれ3つの道標を訪ねる。指定の資源はその地域で採集し、番人がいる地域では討伐する。必要な条件がそろったら野営地の近くで「地域の依頼を報告する」を実行して報酬を受け取る。報告済みの報酬は重複して受け取れない。

次に探すものは、未訪問の道標、指定資源、未討伐の番人、報告する野営地の順。資源が尽きたら再生を、番人が不在なら帰還を待つ。野営地では「焚き火で休む」で元気が35回復する（上限100）。

地上の5地域では報告ごとに「旅の証」1つを得る。3つ集めると「星影の石の森」の星の裂け目から裏世界へ進める。影の庭の帰還の裂け目から地上へ戻れる。影の庭の依頼を報告すると称号「境界を渡る者」を得る。

## 天風の山道（山岳）

雪を頂く山の裾を抜け、風の通り道をたどる。

> 旅人は山頂を競わず、次の旅人のために道を記した。

三つの道標をたどり、この山道で石を4個採集する。

道標：風待ちの岩 → 白い鞍部 → 雲見の峠。

報酬：旅の証 ×1、焼き肉 ×2、木材 ×4。

野営地は地図座標 (736, 263)。

## こだまの峡谷（峡谷）

赤い岩壁の間を、声と焚き火の煙が渡る。

> 絶壁に返る声は、離れた仲間がまだそこにいる印だった。

峡谷の三つの道標をたどり、この谷で木材を4個採集する。

道標：谷の入り口 → こだまの壁 → 見晴らしの裂け目。

報酬：旅の証 ×1、焼き肉 ×2、石 ×4。

野営地は地図座標 (96, 647)。

## 星影の石の森（石の森）

巨石と針葉樹の奥で、青い裂け目が脈打つ。

> 三つの旅の証がそろうと、石の森にもう一つの空が開く。

石の森の三つの道標をたどり、森の番人を倒す。近くの仲間にも討伐が記録される。

道標：苔の広場 → 巨石の回廊 → 星の裂け目。

報酬：旅の証 ×1、焼き肉 ×3、ベリー ×5。

野営地は地図座標 (1008, 135)。

## 琥珀のオアシス（オアシス）

砂岩の輪に囲まれた泉で、旅の疲れを癒やす。

> 砂の旅人は、泉のありかを歌にして忘れないようにした。

泉を囲む三つの道標をたどり、この地でベリーを3個採集する。

道標：砂の灯 → 旅人の泉 → 琥珀の岩。

報酬：旅の証 ×1、焼き肉 ×2、木材 ×6。

野営地は地図座標 (-160, 455)。

## 蒼氷の回廊（氷の峡谷）

青い氷壁のすき間に、凍らない旅路が続く。

> 氷の音を聞き分ける者だけが、白い迷路に道を残せた。

氷の三つの道標をたどり、氷の番人を倒し、石を5個採集する。

道標：青い入口 → 氷鳴りの壁 → 静寂の間。

報酬：旅の証 ×1、焼き肉 ×3、木材 ×5。

野営地は地図座標 (-1568, -57)。

## 裏世界・影の庭（裏世界）

紫の空、浮遊する光、黒い石柱。裂け目の向こう側へ。

> 影は敵ではなく、まだ誰にも語られていない世界の記憶だった。

影の三つの道標をたどり、二人の影の番人を倒す。

道標：帰還の灯 → 忘れられた庭 → 影の奥座。

報酬：称号「境界を渡る者」、焼き肉 ×5、ベリー ×10。

野営地は地図座標 (1008, 1575)。石の森の裂け目から入る。
