# プレイヤー同士の攻撃とノックバック（2026-10-12）

ユーザー指定「MMOで、マルチプレイ時にお互いキャラ同士で攻撃できるようにする。体力は減らないけど、ノックバックする。」に対応した。可視モデル・リグ・クリップは変更していない。公開MMO（Cloudflare）へのデプロイは行っていない（デプロイはユーザーの明示的な指示でのみ行う）。

## 仕様

- **対象の部屋**：部屋の規則 `playerKnockback`（`shared/room-rules.mts`）。通常の規則（公開MMO・ローカル検証・通常のNode版）で有効。終了した展示の規則では無効のまま（展示の記録どおり、他のプレイヤーには当たらない）。
- **当て方**：今までの攻撃操作のまま（F／5／攻撃ボタン／□・R2／スマホの攻撃ボタン）。プレイヤーはクリックで選べないので、向いている方へ攻撃して当てる。初心者向け操作の自動照準は従来どおり敵だけを狙う。
- **当たり方**：近接攻撃は当たる瞬間に、前方の扇形・射程・遮蔽物・同じ高さをサーバーで調べ、生き物とプレイヤーのうち**いちばん近い1体**に当たる。光弾・科学パルスは、飛ぶ途中で最初に触れた体（プレイヤーも含む）で止まる。
- **効果**：相手の元気（体力）、被弾回数（`hurtSequence`）、力尽きる判定は一切変わらない。画面の赤い被弾表示も出ない。攻撃した人から離れる向き（弾は飛ぶ向き）へ押し返す。調理中なら調理だけ中断する（食材は残る）。釣り・貝の採集・撫でる・肩乗りの誘いなどは、体が動くので既存の判定どおり中止になる。
- **押し返す距離**（人間の体の半径0.32mが基準。大きな体は 0.32÷半径 倍、下限0.5倍。大猿は0.5倍、まるぃもは約0.53倍）：

  | 攻撃 | 距離 |
  | --- | --- |
  | 木槍 | 1.6 m |
  | 黒曜石の槍 | 1.9 m |
  | 刀（クノイチ） | 1.4 m |
  | 大きな手（大猿） | 2.6 m |
  | 触手（まるぃも） | 1.8 m |
  | 光の魔法 | 2.2 m |
  | 科学パルス | 1.6 m |

- **滑り方**：0.45秒かけて滑る。速度は指数的に落ちる（減衰9/秒、最初の0.1秒で約6割進む）。サーバー、自分の予測（LANモード）、すべての画面の描画が同じ曲線（`shared/knockback.mts`）を使う。滑りは歩くときと同じ当たり判定を通るので、壁・岩・他の体・川・海岸・世界の端で止まり、水中や段差の向こうへ押し出されない。
- **滑っている間**：自分の移動入力はサーバーが無視し、滑り終わった時点から歩ける。攻撃・ジャンプはできる。滑っている間に受けた次の攻撃は当たっても押し返しを重ねない（複数人で一人を動けなくし続けることはできない）。騎乗・乗船・肩に乗る・力尽きる・ワープは滑りをその場で終える。
- **当たらない人**：自分、騎乗中・乗船中・肩に乗っている人、力尽きている人、焚き火で回復した直後の保護中の人、洞窟の中にいる人。肩の上の魔法使いの光弾は、担いでいる大猿には当たらない。
- **見た目**：押された体は全身が滑る向きへ傾き（最大約17°、約0.07秒で最大、0.65秒で直立に戻る。短い滑りでは浅い）、0.45秒かけて滑る。全身の傾きは人物を包むグループの回転（実行時の変換）で、どの体型・スキンでも同じに見える。誰かを肩に担いでいる大猿は、肩の座席を水平に保つため傾けない。他の人の画面でも、スナップショットとスナップショットの間を同じ曲線で先回りして描く（`knockbackLead`）。
- **音**：自分が押されたとき、または4m以内の他の人が押されたとき、既存の「体への打撃」音（`hurt`）を鳴らす。
- **通知**：攻撃した側に「○○を押し返した。」、押された側に「○○に押し返された。元気は減りません。」を、画面に出さない静かな通知（`popup: false`、既存の方針）で送る。
- **通信と保存**：スナップショットのプレイヤーに `knockbackAt`・`knockbackSequence`・`knockbackX`・`knockbackZ`・`knockbackDistance`・`knockbackDone`（適用済みの割合）を載せる。一度も押されていない人には付けない。ワープの照合用の値は送らない。保存（`exportState`）には含めず、再接続した人は立った状態から始まる。Cloudflareの無料枠の数え方（受信メッセージ・接続・書き込み・稼働時間）と保存の頻度は変わらない。

## 未検証・制約

- 公開MMOへは未反映。MMOのローカルプレビュー（8787番）は、AGENTS.md の規則（ユーザーの指示なしに起動・停止しない、ローカルのMMO保存を使う）により起動していない。Cloudflareのワーカーは同じゲームコアを使い、`tests/cloudflare-core.test.mjs` は合格している。
- 実スマホ、物理ゲームパッド、実際のネットワーク遅延がある状態での見え方は未確認。ローカル検証の実Chromeは遅延ほぼ0ms。
- LANモード（展示）の自分の予測は単体テストだけ。展示の規則では無効なので、展示では起こらない。
- 押された人の脚は動かない（全身の傾き＋滑り）。専用の被弾クリップは作っていない。
- 「押し合い」（体がぶつかったときに押し合う物理）は今回も未実装。
