# mae — 丸い袋のペット

ダウンロードの `mae.jpg` を `assets/mae/source/mae.jpg` へ無加工で取り込み、524・りもねこと同じ世界に新しい1体のペットとして追加した。薄灰色の丸い横長の体、縦の目2本、水平の口を保持する。高さ38cm。手足や画像にない紐は追加していない。

## 遊び方

最初のキャンプの `(53.2,51.2)` 付近にいる。近くでV／E／パッド下、または本体クリックで撫でる。通常メニューの「世界・仲間・操作説明」→「世界」からも操作できる。maeが人物の手に近づき、1.4秒撫でられたあと、小さく2回弾んでハートを出す。喜ぶ1.4秒が終わると追従する。

歩くと左右に揺れ、急いで追うと柔らかく跳ねる。Tまたは通常メニューでキャンプへ帰す。追従・帰還は地形・衝突・経路を使う。切断・乗船・ダウン・60m以上離れた場合と保存復元時にはキャンプへ帰る。新しい保存項目だけ追加し、古い保存にはmaeをキャンプに配置する。

撫で完了前の移動・攻撃・被弾・人物変更・ワープ・切断・Qは中断する。途中中断では新規加入・移管せず以前の所属を保持する。誰かが撫でている間は他者が割り込めない。524、りもねこ、9種類のbotと元GLB・既存操作を保持し、maeをbot投擲の対象には加えていない。常設の新しい画面パネルは追加しない。

## 制作経路

既存の `ASSET_WORKFLOW.md`、`CREATURE_MOTION_GUIDE.md`、Astra品質調査と隣接モデル制作リポジトリの制作・保存・リグ資料を参照した。

1. ユーザー原画像を保存し、built-in imagegenで形と顔を保持した立体用参照を制作。
2. Local TRELLIS-2 v0.8.1 Vulkan、512、seed42、threshold背景除去で復元。実GPUはRTX A1000 6GB Laptop。
3. 溶接・変位を制限した局所平滑化と、元表面との距離を測った削減。UVとアルベドPNGのSHAを保持。布としてmetalness=0、roughness=0.82。
4. Root／Body／Top／PetContactの4骨。2変形骨の滑らかなウェイト、全フレーム接地補正。待機・歩行・走行・撫で・喜ぶ・被弾の6クリップを60Hzで作成。
5. 実GLBの数値・外観・ブラウザー・ゲーム内の確認を経て採用。
