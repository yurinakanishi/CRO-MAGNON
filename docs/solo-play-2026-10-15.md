# ソロプレイとブラウザー内の自動保存（2026-10-15）

ユーザー指定により、通常ローカルと公開用ビルドの入口を当面ソロだけにする。公開サイトへのデプロイは今回行っていない。

## 画面と進行

- タイトルの「ソロプレイで始める」は有効、「オンラインで始める」は無効。日本語・英語に対応。
- 名前・人物・服の色を選んで「次へ」、別画面で仲間を1匹選んで確定する。仲間画面の「戻る」で人物を選び直せる。
- ソロでは部屋のコード・招待・チャット・接続人数・ネットワーク遅延を出さない。内部の部屋名は `SOLO`、上限1人。
- 既存のゲームルールを専用のブラウザーWorkerで動かす。移動・採集・戦闘・持ち物・世界の進行はブラウザー内で完結し、ゲームAPI・WebSocketを使わない。画像やモデルなど静的ファイルの読み込みは引き続き必要。
- 続きから再開した時は人物・服・仲間の今回の選択を反映し、同じ人物のID・持ち物・進行・現在地を復元する。30秒無操作による退出と手動再開は従来どおり。

## 保存

進行にはIndexedDBを採用。localStorageは同期処理のため、名前・操作設定などの小さな設定に限定する。IndexedDBの非同期トランザクションで、世界と再開用の識別子をまとめて保存する。[MDN: IndexedDB](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API)・[Web Storage](https://developer.mozilla.org/en-US/docs/Web/API/Web_Storage_API)。

- DB `cro-magnon-solo`、ストア `checkpoints`。現在分 `current` と、前回正常に保存できた分 `previous` を保持。
- 最初の入場は保存成功後に受け付ける。持ち物・資源・戦闘結果・人物・服・仲間などの変化時、約3秒ごと、タイトルに戻る時に保存。タブを隠す時も保存を依頼する。
- `put` の成功ではなく、トランザクション全体の完了をもって「自動保存済み」と表示する。保存失敗は画面へ通知し、前回の正常な記録を保持する。失敗後の定期再試行は5秒間隔に抑える。
- JSONとSHA-256を照合して破損を検出。現在分が破損していれば予備を検証して復元する。両方の破損や未対応の新しい形式は開始を拒否し、勝手に初期化しない。復元後も破損した現在分を予備へ上書きしない。
- Web Locksで同じ保存への書き手を1タブに限定する。別タブでは説明を出し、最初のタブをタイトルへ戻すか閉じてから再開できる。
- 保存は同じオリジン（プロトコル・ホスト・ポート）とブラウザープロフィールに属する。他端末への同期はない。サイトデータ削除・プライベートブラウズ終了・ブラウザーの容量回収で消える場合がある。強制終了直前の未保存の進行は保証しない。[MDN: 保存容量と削除](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。
- Web Locksと暗号化ハッシュを使うためHTTPSまたはlocalhostで開く。保存を利用できない環境では、保存できたふりをして開始しない。

オンライン用の `.cro-magnon-save/` やCloudflareのSQL保存は読み込まず、ソロへ自動移行しない。既存のオンライン用再開情報も別キーで保持する。

## 公開用の境界

`src/multiplayer-config.ts` は通常の起動をソロへ固定し、旧設定が `online` でもゲーム通信を開始しない。終了した展示用のLAN設定は保管する。公開用の設定ファイルも `mode: "solo"` にする。

`wrangler.jsonc` の `SERVICE_ENABLED` は `false`。`cloudflare/request-handler.mts` は `/ws` と `/api/status` を `env.GAME` へ触れる前に拒否する。静的ファイルは既存のassets-first配信。以前のオンライン保存を残すためDOのbinding・class・migrationを削除しないが、ソロの起動ではDOを生成・呼び出しせず、SQLも開かない。通常の保存先はIndexedDBだけ。[Cloudflare: Static Assets](https://developers.cloudflare.com/workers/static-assets/binding)。

ブラウザーWorkerは `infrastructure/browser/` と既存の `application/` をまとめたもの。通常配信では `/shared/` の現在の可視設定を参照し、公開用ビルドでは公開用に絞った共通データからまとめ直す。元のモデルや休止中の素材を復帰させない。
