# 洞窟内の攻撃禁止と松明だけの手持ち（2026-10-06）

ユーザー指定により、アプデの洞窟内では全9人物の攻撃を禁止した。洞窟の実測された床・屋根から求める既存の `caveInteriorWeight` と同じ境界を使う。入口外のアプローチ、岩の外、洞窟より上の山は対象にしない。

クライアントの共通操作、近接判定、操作案内、タッチの攻撃ボタンを停止し、権威側も直接の攻撃コマンドを拒否する。攻撃の予備動作中にワープ・肩乗りで洞窟へ入った場合は、命中・魔法の発射も止める。持ち上げられた魔法使いの古い座標からの回避も拒否する。

洞窟内の槍・黒曜石の槍・刀・石斧は描画から隠す。松明の手持ちと火を分離し、消しても木の松明と握る姿勢は残す。炎・明かり・燃焼音は消灯状態に従う。L・メニュー・タッチの表示を「松明を消す／松明を灯す」へ変更した。松明を消して武器へ持ち替える状態はなく、外へ出ると従来の装備表示へ戻る。

松明以外を手に持たないよう、洞窟内の仲間の投擲を拒否し、入口を越えた時の未発射の持ち上げを中止する。仲間の所属・同行・撫でる・呼び戻し、洞窟の共用の炉、所持品・装備・進行の保存は保持する。既存GLB・材質・リグ・配信用音源は変更しない。
