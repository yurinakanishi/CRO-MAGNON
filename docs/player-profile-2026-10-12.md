# 近くの旅人の自己紹介とステータスを見る（2026-10-12）

ユーザー指定「近くに行ったら、相手の自己紹介とか、ステータスとか見られるようにしたい。」に対応した。

## 見る

- 近く（8m以内）で画面に映っている旅人は、仲間と同じ「見る」の対象になる。案内は「〇〇を見る」（PC：X、パッド：R1、スマホ：画面右の案内）。旅人の体をクリック／タップするか、ホイールで近づいても見られる。
- 見ている間はその人に寄るカメラになり、札（プロフィール）を表示する。PCは画面左の中ほど、スマホは移動パッドが消えた左下に置き、近く／遠く／戻るの案内と重ならない。頭上の名前は札と重なるので隠す。
- 札の内容：名前、キャラクター、自己紹介、体力、装備、連れている仲間（いなければ「ひとり旅」）、旅の証（n/5）、採集数、称号（影の庭を達成した人だけ「境界を渡る者」）。持ち物や地域の途中経過など、ふだん周りから見えない情報は出さない（`shared/player-profile.mts` の `playerProfile`）。
- 自分が歩く・被弾する・乗る、相手が12m以上離れる、または戻る（Esc・戻る）で終わる。仲間を見るときと同じ規則。
- かんたん操作（自動カメラ）では、仲間の「見る」と同じく使えない。この操作方法で札だけ出す対応は、2026-10-12のユーザー指定で保留とし、実装しない。

## 自己紹介を書く

- 左上の自分の欄（スマホは状態カプセル）を押して開く「同じ火を囲む仲間」に「あなたの自己紹介」欄を置いた。80文字まで、1行。Enterか「保存する」で保存し、届くと「保存しました」と出る。
- サーバーは名前と同じ方法で整える（前後の空白・改行などの制御文字を除き、80文字に切る）。変更は1秒に1回まで。展示版は会話と同じく自由文を扱わない。
- 自己紹介は人物の保存（セッション）に残る。部屋にいる全員へ、参加時と変更時だけ `intros` メッセージで送り、頻繁な状態送信には含めない（通信量を増やさない）。
- 英語表示でも本人の文はそのまま表示し、空のときの「まだ自己紹介はありません」と項目名だけを訳す。

## 確認

- 新規 `tests/player-profile.test.mjs` 6件：コマンドの検査、参加時と変更時の配信、状態送信に含まれないこと、80文字・制御文字・1秒の制限、再起動後の保持と不正な保存の整え直し、展示版で無効、札に出す情報と出さない情報。
- `npm run check`（型・strict・643 JS構文・依存境界）、`npm run format:check`、差分空白は合格。関連14テストファイル204件は合格。全体は1,635件中1,630合格・4件は条件付きスキップ。残る1件は `tests/environment-profiles.test.mjs` で、全サブテストの合格後にプロセスが終了時に異常終了（Windows 0xC0000409）した。単独の再実行では11件すべて合格。
- 実Chrome `scripts/qa-player-profile.mjs`（保存なしの独立サーバー、3人）で15項目に合格し、ブラウザーエラーは0。確認した内容：自己紹介の保存と「保存しました」、英語画面のBへの「Look at Companion A」案内、Xで寄って札を表示、本人の文がそのまま出ること、Aが仲間を選ぶと札に反映されること、歩くと札が閉じること、クリックで開くこと、Escで戻ること、スマホ縦（390×844）のタップで開くこと、札が画面内に収まり案内と重ならないこと。
