# ローカル版のキャラクター表示設定

追記: Howkeyさんも非表示にした。現在は `local-visibility.json` の `howkey: false` を含む3項目で切り替え、人物選択は7人。最新の設定と検証は [Howkeyさんの非表示](howkey-visibility-2026-10-03.md) を参照。以下はmae・まるぃもさんを切り替えた時点の記録。

maeとまるぃもさんは、素材を削除せず非表示にした。通常のローカルサーバーだけが、プロジェクト直下の `local-visibility.json` を読む。

```json
{
  "mae": false,
  "maruimo": false
}
```

- `false` は非表示、`true` は表示。2つを別々に切り替えられる。
- 現在動いている `npm run dev` では、保存すると既存の監視処理がビルドと正常終了保存を行い、設定を反映する。ビルド完了後にゲーム画面を再読み込みする。
- `npm start` / `node server.mjs` で起動する場合は起動時に読むため、設定変更後に正常終了・再起動が必要。
- JSONの項目名や値が不正な場合は起動エラーにし、意図せず表示へ戻さない。設定ファイルがない旧環境では従来の全表示を使う。
- 公開Cloudflare版の `cloudflare/public-release.json` と展示版の設定は別。今回の設定ファイルは配布しない。公開・展示の更新は行っていない。

## 非表示の範囲と復元

まるぃもさんはタイトルとプレイ中のキャラクター選択から外れ、通常の選択肢は8人になる。maeは生成・通信スナップショット・3D読込・操作対象から外れる。524、りもねこ、botたちと他の8人物は継続する。

サーバーが人物カタログとワールドのモデル一覧をフィルターし、両モデルのディレクトリーへの直接アクセスも404にする。URLの大文字・エンコード・正規化後のパスにも適用する。ブラウザーだけで非表示にする処理ではない。

旧ブラウザーや保存情報からまるぃもさんが指定された場合、使用中の姿はクロマニョン人へ置き換える。ID・持ち物・位置・進行を保持し、以前の姿を非公開の保存フィールドへ退避する。再表示後の保存復元・再接続で元の姿を戻せる。ユーザーがタイトルやメニューで別の人物を明示的に選んだ場合は、その選択を優先する。隠した人物への通信による変更要求は拒否する。

maeの非表示前の保存データは非表示中もそのまま保存し続ける。再表示時には既存の `restoreMae` で復元する（以前からの仕様どおり、追従中だったmaeは保存位置からキャンプへ戻る）。新規の部屋ならキャンプに生成する。元画像、GLB、LOD、骨、動作、材質、制作候補を変更・削除しない。
