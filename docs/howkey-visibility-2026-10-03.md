# ローカル版のHowkeyさんを切替可能な非表示へ

ユーザー指定により、Howkeyさんを通常ローカル版から非表示にした。既存のmae・まるぃもさんの非表示も維持する。人物選択は7人になる。

プロジェクト直下の `local-visibility.json` は次の設定。

```json
{
  "mae": false,
  "maruimo": false,
  "howkey": false
}
```

`howkey` を `true` にして保存すると、既存devのビルドと正常終了保存を経て再表示できる。ブラウザーは再読み込みする。`npm start` や持ち運び版は設定変更後に正常終了・再起動する。古い2項目だけの設定ではHowkeyさんを表示する互換性を維持し、値の型と未定義の項目名は検査する。

非表示中は人物カタログから除外し、主GLB・両LOD・顔画像・asset.jsonの全5ファイルへの直接URLを404にする。非表示の姿を指定した古い保存や参加要求はクロマニョン人へ代替し、元の姿を非公開の保存フィールドに残す。設定を戻すと保存復元・再参加で元の姿へ戻る。明示的な別人物選択は既存仕様どおり優先する。隠した人物への通信上の変更要求は拒否する。

Howkeyさんのモデル、画像、骨、動作、制作素材を変更・削除しない。ゲーム内に管理画面や説明を追加しない。公開Cloudflare・展示の設定は従来どおりで、公開先へのデプロイや配布物の更新は行っていない。

## 確認

- 3項目の8組合せで、人物カタログ、モデル配信・404、古い人物指定を検査。主/LOD/旧LOD/顔画像のURL、大小文字・エンコード・正規化後のパスも確認。
- Howkeyさんとまるぃもさんの元の姿・持ち物・進行を、保存→非表示→保存→再表示で保持。実ファイルを読む永続Nodeホストでも復元を確認。
- 関連22テスト成功。全体検査の初回は、人物を元から含まないワールド素材一覧に人物があると期待した検査の誤り1件で停止。人物カタログとワールド一覧の役割に合わせて検査を修正し全体を再実行。初回ログ `output/howkey-visibility/tests.log` を保持。
- 再実行の全894テストが成功（`output/howkey-visibility/tests-final.log`）。通常・strict・Cloudflareの型検査を含むビルド、461 JavaScript構文、依存境界、変更ソースと文書の書式も確認。
- 実Chrome2画面＋通信3人で7人物、3体の非表示、旧Howkey/まるぃも参加の代替、移動・人物変更の同期、偽変更の拒否、再参加、縦長・横長を確認。モデル・顔画像の要求0。
- 別の保存なし検証ホストですべてをtrueにし、9人物、Howkeyさんとまるぃもさんとmaeの元モデルの描画を確認。通常ローカルの設定は検証用に再表示していない。
- ブラウザー4検査群・8画像、エラー0。証拠 `output/playwright/local-visibility/1791023134065`。

通常3000番で7人物と3体の素材URL計15件の404を確認。3体の主/LOD計6GLBのSHAが元manifestに一致。保存3部屋・6セッション、保存正常・復旧なし。設定変更直前とのプレイヤー差分は接続中の旅人1のlastInput/refillAtのみで、位置・持ち物・人物・進行を保持。
