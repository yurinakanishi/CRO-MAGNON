## 人物単位の差し替え

[設定](../cave-mural-visibility.json)は壁画専用で、現在は `hidden: []`。ゲームのキャラクター選択、クレジット、`local-visibility.json` とは独立している。

```powershell
# 例：Howkeyだけ動物画へ差し替える
npm run cave:murals -- --hide howkey-scientist
# 元に戻す
npm run cave:murals -- --show howkey-scientist
# 採用せずに画像だけ確認する
npm run cave:murals -- --hide maruimo-mascot --preview output/mural-preview
# 現在の設定と配信ファイルの一致を確認する
npm run cave:murals -- --check
```

生成原本・プロンプト・1024×341の動物画・22人分の領域と隣人保護マスクは [modular-r36](../assets/camp-cave/modular-r36/README.md)。内蔵imagegenで8群に対応する動物版を制作し、草原群のみ小さなアイベックスを追加したr02を採用した。旧画像・不採用版も保持。全生成プロンプトは `prompts.json` と `friendsMeadow-r02-prompt.txt`。

合成は配信前に行う。指定された人物の領域だけを動物版と入れ替え、境界の内側4pxを馴染ませる。重なる隣人の輪郭内は元画素を保持する。透過率を考慮した合成で、四角い石色の背景を貼らない。人物を表示する群は元PNGをバイト単位でそのまま使い、外した群だけ別SHAのPNGを作る。元の素材・ゲームの配置・GLBは保持する。

`asset.json` と `world-assets.json` を同時に更新し、合成由来を `provenance.muralComposition` へ記録する。再表示で元の配信PNGと由来へ戻る。現在は差し替え指定が空なので、配信画像は従来の10枚のまま。動物版8枚は制作資料であり、ゲームの追加ダウンロードには含めない。

元画像や最適化後の配信基準が変わった場合、既存recipeを無条件で重ねない。コマンドは別の原本SHA・未把握の配信SHAを拒否する。素材の採用変更後も `--check` を実行し、必要なら新しいrecipe revisionを制作する。
