# 撫で始めた時点でなつく

ユーザー指定により、りもねこ・524・9種類のbot・再表示時のmaeは、サーバーが撫でる操作を受け付けた瞬間にその人の仲間になる。接近、撫でる動作、ハートの完了を待たない。以前の「中断すると未加入」「完了した撫でで移管」よりこの仕様を優先する。

近接・壁・使用中の動作・他者との競合の検査は、仲間にする前に行う。届かない場所からの要求、飛行中のbot、同時に別の仲間を撫でる要求などは従来どおり拒否する。一括撫ででは受け付けた全員が同じ更新で加入し、他者に所属しているbotは一括の対象にしない。個別の撫でを受け付けた場合は、その開始時点で新しい持ち主へ移管する。

歩行・攻撃・被弾・人物変更・ワープ・切断などで撫でる動作を中断しても、成立した所属は残る。りもねことmaeも被弾時の反応を保ちながら所属を残し、切断・乗船・遠距離等でキャンプへ戻る場合は所属を保持する。持ち主が追従可能な位置へ戻れば追従を再開する。保存からの復元は、既存プレイヤーIDを検査して所属を復元し、途中の撫でる動作は再生しない。

Q／集合は、りもねこ・mae・524・botの一括撫でを解除しても所属を残す。明示的な「帰す」「全員を帰す」「ひとりで歩く」は従来どおり所属を解除する。botを1匹だけ帰したときは、一括の動作は終えるが他の加入済みbotは残る。

元モデル、骨、動作、ハートの時間、接近動作、投擲と着地点待機、524の浮遊、りもねこの威嚇を保持する。保存形式と公開スナップショットの項目は増やさない。mae・まるぃも・Howkeyの通常ローカル非表示を維持し、操作説明や管理画面は追加しない。
