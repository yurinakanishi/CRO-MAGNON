# 右手／左手だけで遊ぶ（2026-10-05）

ユーザーの追加指定により、片手で移動とアクションを行えるようにした。さらに「ユーザーが左右を選ばなくてよいように」と指定されたため、開始時に見せた片手を自動判別する。右手・左手・両手の選択欄は撤去し、以前の保存された選択も使用しない。

Hand Landmarkerの左右分類を使い、開いた掌と指先が確認でき、分類スコア0.75以上の手から登録を始める。最初の候補を保持して300msの安定確認を行う。両手が同時に映った場合は最初の掌の投影面積が大きい方を候補にする。登録中に別の手へ替えた場合は認識の最初からやり直し、2つの手の停止位置を混ぜない。登録後の一時的な喪失・再開・枠外保持では手を替えず、明示的に位置を合わせ直す／起動し直すと自動判別をやり直す。

選んだ手の押し引きで前後、左右で旋回、戻す／下ろすと停止。同じ手を銃の形にすると攻撃、開いて上げるとジャンプ、低い横振りで撫でる／調べる。アクション中は移動と旋回を止め、元の位置で120ms確認してから移動へ戻る。視点は完全自動。

片手の登録・再開・認識表示には反対の手を要求しない。反対の手が映っても操作を奪わない。Calibrationは使わない手をnullで保持し、尺度は使用手の掌幅から計算する。内部の従来の両手入力は互換性を保ち、ゲーム画面からは片手の自動判別を使用する。

片手の上下判定も押し引きの投影補正を共用する。ジャンプと横振りの開始は掌の大きさが停止位置付近（±12%未満）のときだけ。最初の試作では前後操作の上下ずれでアクション待ちに入り、動画の移動が停止していたため、この条件を追加した。大きく押し引き中は上下のアクションを始めない。銃形は別に判定する。

画面端から外れたときの移動保持、230msの結果失効による停止、メニュー／画面離脱時の停止を保持。準備や切替では攻撃・ジャンプを発動しない。案内、対象の手の名前、詳細の認識数（1/1）を選択に合わせる。
