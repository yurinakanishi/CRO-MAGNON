# 操作説明を読む画面から、プレイ中の入力図へ

ユーザー指定で、タイトルの「あそびかた」、H／? の説明画面、一時停止メニューの「操作説明」、PC／パッドの説明カードを削除した。クラフト・bot・設定の遊び方の文章、湾・釣り・作物・沿岸・航路の折りたたみ説明欄も削除。探索手帳の長い地域紹介を外した。持ち物、材料・効果・進行の数値、取引、住人との会話、保存障害やリセットの確認は保持する。

## 画面と入力

- キーボードでは WASD／Shift とマウス図、近くの物や仲間に対応する短いキー表示。
- パッドでは本体のベクター図を表示。右4ボタン、十字4方向、左右スティックと押し込み、肩・トリガー・中央ボタンを個別に描画する。今できる操作は金色の輪、実際の入力は明るい塗りと光で示す。左右スティックには短い行動名を添える。
- Switch Pro は非対称スティックと A/B/X/Y・L/R/ZL/ZR、PS系は対称スティックと記号・L1/R1/L2/R2、Xboxは非対称とA/B/X/Y・LB/RB/LT/RT。ブラウザー標準マッピングだけを受け付け、未知の機種は位置で表記する。機種判別はボタン割り当てを変更しない。展示の明示的な表記設定も保持する。
- 対応パッドがブラウザーへ接続すると図へ切替。キーボード・マウスを使うとキー表示へ、パッドを使うと図へ戻り、切断時はキーボードへ戻る。オンラインの各参加者が自分の端末で判別する。
- 状況に応じた行動は最大3つ。近接の撫でる・採集・乗降、近くの生き物への攻撃、投げる／呼び戻す、食事が必要なときの持ち物、キーボードの松明、ジャンプを表示する。パッド下の「撫でる優先」は既存の実際の処理と合わせる。
- メニュー、地図、チャット入力、タイトル、ダウン、非表示・フォーカス喪失、カメラ操作中はプレイ用の図を隠す。メニュー内の操作説明には置き換えない。画面上の短い行動表示はクリック／タップでも同じ処理を呼ぶ。
- 中央のホームボタンにはゲーム機能を追加していない。OSや機器がブラウザーへ通知しないボタンの押下は表示できない。

本体図は拡大・縮小しても位置がずれないSVG。画像・3Dモデル・通信・保存形式・ゲームの割り当ては変更しない。外部パッケージや画像生成への依存は追加していない。押下表示は既存のGamepadサンプルを共用し、変化がないフレームのDOM更新を抑える。点滅や必須のチュートリアルは設けない。

## 検証

全878テスト、最終関連46テスト、TypeScript／strict、456JS構文、依存境界を確認。削除した説明画面を前提とした既存テストとメニューQAも更新した。

実Chromeによる2画面＋通信3人、保存しない独立したサーバーで確認する検査は `scripts/qa-input-cues.mjs`。標準Gamepad APIだけを合成し、人物・仲間・3D描画・通信は実際のゲームを使う。キーボード移動、接続・切断・機種切替、スティックとボタンの光、撫で・ハート完了・投擲・呼び戻し、メニュー・地図の往復、390×844／844×390／1280×800、チャット入力を検査した。初回の完了結果は `output/playwright/input-cues/1791005996017/report.json`、画像11枚、ブラウザーエラー0。

その後、パッドの案内をマウスでクリックした際、押し始めに入力図が切り替わって対象ボタンを消さないように修正。採集・攻撃とこのクリック操作を検査に追加した。採集検査は近くの加入botがEを優先する既存仕様を考慮し、通常のメニューでbotを帰してから採集場所へ移す。準備位置はキャンプbotのそばとベリーのそばだけ。最終実行は `output/playwright/input-cues/1791006545542/report.json`。7群すべて成功、画像12枚、ブラウザーエラー0。最終の全878テストも再実行して成功した（`output/input-cues/unit-tests-final.txt`）。物理コントローラー、実スマートフォン、長時間FPSは未検証。

機種名に `Wireless Controller` を含むXboxがPS系へ分類される問題は、Xboxの判別を先にすることで修正した。初回の機種検査の失敗、採集の準備条件とニュートラル入力待ちを修正する前のQAも削除せず保存した。
