# 公開版の軽量化（2026-10-02）

公開先は既存の `cromagnonmmo.cro-magnon.workers.dev`。同じWorkerとDurable Objectを使い、無料枠・5人上限・公開クレジット・非公開人物の除外を継続する。元のGLBとローカルの全9人物は保持する。

## 実装

- タイトルと通常メニューの設定に「自動／軽量／標準」。ブラウザー内に保存する。軽量は30fps、描画バッファ最大1280×720相当、装飾草50%、環境粒子128/384、浮遊粒子24/65。DOMの文字・操作部は縮小しない。
- 軽量はリアルタイムの太陽の影を、1回のインスタンス描画による人物・動物・仲間の柔らかい接地影へ切り替える。標準は従来の毎フレーム更新の影。低頻度のシャドウマップ更新は行わず、以前の動く身体のちらつきを再導入しない。
- 自動は4論理CPU以下またはブラウザーのメモリー申告4GB以下なら軽量から開始。それ以外は標準から開始し、読込後8秒を除外した3秒窓で45fps未満が2回連続すると軽量へ変更する。タブ非表示・地図での遮蔽・大きな停止を除外し、同一セッションでは自動昇格しない。手動で標準へ戻せる。
- 公開用画像は主に最大1024px、人物は2048px。リモねこは縮小時のUV境界の色にじみを目視で検出したため、元の2048px画像を保持。PNGでアルファを保持し、非画像bufferView・頂点・UV・材質・骨・全動作は完全一致。今回KTX2は採用せず、追加デコーダーを増やさない画像寸法の削減を採用した。
- 524と猫には元GLBからBlender 5.2の形状を保つ削減でLODを追加。524は可視主面449,022→35,921三角形、猫136,745→21,879。元のリグ・クリップ・材質を共用。標準では3.5m／6m、軽量ではその半分の距離を中心にヒステリシス付きで切替える。
- 初期の地形・拠点・動物を先に準備し、11種類の仲間は2件までの後続キューで検証付き読込。表示準備完了を待つGLBは207.86MiB→79.36MiB。後続の仲間まで含む同じ素材集合は139.58MiB。人物・遠隔地域等は別枠。
- 画面内の近い仲間は毎フレーム、遠い仲間は15Hz、画面外は5Hzでループ動作を更新する。位置・通信・投擲・着地・撫でる反応を間引かない。再表示時はすぐに姿勢を更新し、524の浮遊は共有時刻を使う。
- 公開GLBは内容のSHAを含むURLと長期キャッシュ。manifest・JSは再検証する。公開素材の総容量は後述のビルド記録を参照。
- 最近追加された投擲の人物別オフセットを人物定義へ移した。公開版の定義から対象人物を除くため、非公開人物固有の値もブラウザーとWorkerのどちらにも含めない。

## 素材の再現と復元

`scripts/build-performance-lods.py` で元GLBからLODを制作し、`scripts/prepare-public-performance.mjs` で元SHAを照合して公開用画像を生成する。PythonはPillowを要する。別環境は `PERFORMANCE_PYTHON` に実行ファイルを指定する。派生物・元の参照・QAを上書きせずに保管する。

`assets/public-performance/manifest.json` に原本SHA・派生SHA・画像寸法・ファイル名を記録。`scripts/verify-public-performance.mjs` は101 GLBの14,150個の非画像bufferViewをバイト照合した。原本変更時は公開ビルドが古い派生物を拒否する。

`cloudflare/public-release.json` の `optimizedAssets:false` で公開ビルドの画像を原本へ戻せる。`credits:full` はクレジットの復元、`excludedCharacters` は人物の公開可否として別に管理する。ローカル配信は元画像を継続する。品質設定はいつでも標準へ戻せる。

## 最終の連続測定

実Chrome1画面と通信4人、5人45bot・524・猫を拠点で同時表示した。軽量は600.009秒・17,733フレーム、平均29.55fps。比較用の標準は15.016秒の短い観測であるため、持続性能の対称な比較とは扱わない。

| 指標 | 元の公開ビルド・標準 | 軽量化後・軽量 |
| --- | ---: | ---: |
| 描画バッファ | 1280×800 | 1214×758 |
| 平均fps | 31.83（15秒） | 29.55（600秒、上限30） |
| フレーム間隔 p50 / p95 | 33.3 / 49.9ms | 33.3 / 50.0ms |
| 最終フレーム三角形数 | 5,772,674 | 2,379,974 |
| 最終フレーム描画呼出し | 235 | 166 |
| worldSceneReady | 7,360ms | 3,133ms |
| 観測した読込データ | 458.44MiB | 357.14MiB |
| JSヒープ最小～最大 | 1297.68～1326.89MiB | 1003.33～1173.93MiB |

軽量の10分間はgeometry数107、texture数113で変動なし。ヒープは最初1129.66→最後1037.95MiB。これはJSヒープの観測でありGPUメモリーやPC全体の使用量ではない。ロード時間と転送量はローカルHTTPの冷キャッシュ測定で、実インターネット回線の所要時間を保証しない。

その後にキーボードの9連投・待機・Q集合、設定の30→60→30切替、縦横画面、設定の再読込保持を確認し、ブラウザーエラー0。連続測定は拠点の待機場面で、全地域の10分間走行や物理的な低メモリー端末ではない。証拠 `output/playwright/low-spec/baseline-final`、`sustained-final`。

採用公開ビルドは447ファイル・469.8MiB・101 GLB（2個を分割）。同じ最新版の軽量化前は445ファイル・588.6MiB・99 GLB（4個を分割）。101 GLBの原本合計555,254,612 bytesから派生合計427,717,512 bytesへ削減した。
