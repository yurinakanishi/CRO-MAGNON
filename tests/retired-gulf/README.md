# Retired Pacific island specifications

The user removed the fictional island and its settlements on 2026-09-22.
These twelve former suites describe the removed farms, residents, fisheries,
pantries, trade hub and geography. They are retained verbatim as historical
specifications (`.txt`), not tests of the current world.

`../pacific-removal.test.mjs` checks the replacement behavior: original ocean,
no live island sites or colliders, rejection of old destinations, preservation
of other land and personal inventory, and safe old-save arrivals and boats.
The active boating, cooking, combat, persistence and map suites remain in use.
